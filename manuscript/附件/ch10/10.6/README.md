# 10.6 LLM-as-Judge协议 附件

本目录是2026年10月30日为新结构重编的自包含教学练习，不是遗失旧读者包的原字节恢复。输入是编者构造或预置判断，非史实、非模型输出。正文旧例保留用于阅读方法，不能拿它的数值充作本输入的输出。

## 先做什么

先建立人工参考，再将候选匿名标成A、B，要求评判模型引用支持评分的原文位置。交换呈现位置时，记录真实候选身份而非只抄“A胜”。本表是人为预置的偏差练习，脚本只对照记录，不调用评判模型。遇到顺序变化导致选择翻转，回查理由；不要用更多评判调用自动投票替代原文复核。

## 文件与使用

- input.json：脚本实际读取的输入和配置，UTF-8。
- input.csv：同一教学样本的表格阅读副本；列表或对象使用JSON字符串。编辑后须同步JSON，程序不会自动合并两份。
- field_dictionary.json：字段填写依据和待补定义。
- worksheet.md：本节具体操作记录。
- result_template.csv：待填结果，当前NOT_RUN，不是已完成输出。
- ../workbook.py：本章标准库教学脚本，依据mode选择本节操作。
- evaluation_rubric.md：人工与评判器的逐维尺度。

## 读者需要运行时

进入本目录，使用已有Python 3执行：

```text
python -B ../workbook.py --input input.json
```

脚本只读本地输入并在终端打印JSON，不联网、不安装、不调用模型、不修改输入、不自动保存结果。需要留存时，先确认新文件名，再自行保存终端输出。当前版本所有计算脚本为 **NOT_RUN**：本次只编写，不复算、不训练、不把预期当实测。尚未在读者环境执行，可能需要后续调试。

## 看什么结果

成果应为：固定评判模板、顺序交换表与人工对照记录。先从一条编号回到原句或像素，再解释汇总的分母。分母为零时脚本输出null而不是伪造零分。

判断题：评判器与人一致，是因为看懂证据，还是碰巧选择了更长的候选？

## 迁移真实课题

另建课题输入版本，替换教学来源与编号，保留原文或图像位置；不要把其他节的独立例子合并成更大样本。模型调用、下载数据和训练不由本脚本执行，若采用需另记录模型和数据版本、来源切分、成本和实际状态。

实现依据：Python官方[csv](https://docs.python.org/3/library/csv.html)与[json](https://docs.python.org/3/library/json.html)文档。本次仅查明标准库输入输出接口，不据此声称学术脚本已通过测试。

固定评判模板见judge_prompt.txt；填入双大括号槽位后人工检查完整输入。该文件不发起模型调用。交换位置时同步交换显示文本和候选编号，保留原始身份。
