## 先做什么

把同一张教学页面上的目标框与三个预置候选放在一起，先约定xyxy坐标、原点在左上且右下边界不含。按置信分数排序后，同类预测与尚未匹配参考作一对一匹配。D03重复框不能再拿一次真阳性，D04虽位置重合但类别不同也不算找对。附件评估的是框，不生成神经网络检测结果。

- field_dictionary.json：字段填写依据和待补定义。

## 读者需要运行时

进入本目录，使用已有Python 3执行：

```text
python -B ../workbook.py --input input.json
```

脚本只读本地输入并在终端打印JSON，不联网、不安装、不调用模型、不修改输入、不自动保存结果。需要留存时，先确认新文件名，再自行保存终端输出。当前版本所有计算脚本为 **NOT_RUN**：本次只编写，不复算、不训练、不把预期当实测。尚未在读者环境执行，可能需要后续调试。

## 看什么结果

成果应为：bbox输入、匹配记录与误检漏检清单。先从一条编号回到原句或像素，再解释汇总的分母。分母为零时脚本输出null而不是伪造零分。

判断题：高重叠但类别错、类别对但位置偏，各应如何进入评价？
