# 第17章社会网络教学附件

## 性质与状态

本目录沿用正文底本的八人名册A—H和九个寄信事件T01—T09，依据其条件重新制作输入与程序。它不接续第16章P编号人物，不对应真实闽南史实。没有恢复原读者包程序；新实现不是原件。

**交付执行状态：NOT_RUN。** 本轮未运行任何脚本、模型计算、复算、测试或独立校对验收。正文旧例数字照录为教学示例，不声称由本目录重现。当前不交付假造的数值输出、运行日志或“通过”标记。

## 输入与来源

- `nodes.csv`：X0名册预先列出的A—H；H有独立边界依据，不因没有边就移出。
- `events.csv`：九条已给定确认的有向寄信事件，保留事件时间、来源组与位置。
- `sources.json`：X0—X4的新写合成来源摘录。摘录满足正文条件，不冒称恢复旧包逐字原文。
- `model_spec.json`：固定名册、时间规则、方向、二值存在、中心性和社群口径。
- `interpretation_register.csv`：主张、竞争解释、所需材料与待查状态；不是历史结论。
- `data_dictionary.md`、`source_extracts.md`：字段字典与可人读的完整摘录。
- `network_structure.svg`：依据正文边表手工绘制的结构示意，边旁标T编号；不是计算结果。
- `network_analysis.py`：Python标准库新编实现。

模型定义链接沿用正文NetworkX官方文档，不要求安装NetworkX。历史方法来源沿用Lemercier 2011年存档稿halshs-00521527v2的底本引用；本次未重新核读外部页面。方法来源不能证明合成史事。

## 由读者另行执行

使用Python 3.10或以上，无安装、联网、账户或LLM调用。把本目录复制到个人工作目录后运行：

```bash
python network_analysis.py --data . --out run_base_new
```

`--out`必须是尚不存在的目录，其父目录须已存在。程序不覆盖结果、不修改输入、不删除文件。失败后另选新目录，不把未完成输出当作成功报告。

窗口和分辨率可在独立结果目录改变：

```bash
python network_analysis.py --data . --out run_window_new --start-year 1703 --end-year 1705
python network_analysis.py --data . --out run_gamma_new --gamma 0.5 --gamma 1 --gamma 2
```

内置敏感性和早/后窗比较针对本章A—H练习，不能把任意别的实体表替入后仍默认这些情境有意义。真正扩展研究前须重新界定总体、来源和情境。

## 算法与边界

无向存在边按任一方向至少一次确认寄信构建，事件次数另存，不作关系强度或距离。最短路为无权；介数不计端点、无向双计数除二，再除全图其他节点无序对数。接近中心性为可达比例乘可达人数/距离和。分量包括X0中的孤立点。

社群用极小图集合划分穷举，精确Fraction计算模块度，保存并列最优解。默认非孤立点上限8，超过即停止，不静默换用启发式。H等零度节点单列只是展示约定，不是模块度确定了其历史群体。γ之间的Q值不作“历史真实性”高低比较。

敏感性只构造派生视图：BE为无来源假设，不回写事件；整组来源缺失不同于独立随机缺边；节点移出是静态结构情境，不模拟人物死亡或离任。比较窗固定写在正文教学协议，不随主时窗改写；观察覆盖相同与否仍须人工判断。

本程序不评估信件内容、实际传递、政治权力、亲密程度、社群历史名称或档案独立性。能重复一个结构计算，不等于其历史解释成立。
