# 来源链 价值判断与景观研究练习

本版新制教材配套。真实来源的整理值、教学设例、空白模板分开标记。代码状态 NOT_RUN，未作本轮学术复算或语言校对；文件结构检查不代表计算结果通过。

[判断层次](claim_layers.csv)把事实、计算、解释与价值区分，但不把价值判断排除出历史研究。[来源链示例](source_chain.json)与[回流情境](recirculation_scenario.md)说明同一说法怎样被误作多方印证；回流全部是教学设想，不是实际传播事件。

[四地问题框架](regional_agenda.md)保留厦门、泉州、漳州、台湾的过程差异；[竞争解释表](explanations_template.csv)用相同问题比较行政、市场、专业与资料条件，而不是预先给地区贴原因标签。[判断札记模板](judgment_note_template.md)用连续论证说明历史条件和价值理由，不以打分代替立场。

已有Python可执行 `python -B inspect_source_chain_NOT_RUN.py`，只查ID、缺失引用与结构环。无结构环也不证明资料独立；有环也需回到形成过程解释。程序不核实史实、不判定文化是否消亡，不审计私人资料。

[更正练习](correction_exercise.md)将错误带回主文和下游使用位置。读者只在自己获准的范围内操作，不据本练习自动发信、改网页或公开材料。
