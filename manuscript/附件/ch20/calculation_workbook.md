# 计算与解释工作表

先由population_values.csv抄入Q2010、Q2020、F2010、F2020，检查单位与原位置。

| 项目 | 算式 | 读者实际结果 | 状态 |
| --- | --- | --- | --- |
| 泉州增量 | Q2020-Q2010 | 待填 | NOT_RUN |
| 全省增量 | F2020-F2010 | 待填 | NOT_RUN |
| 泉州十年增长率 | (Q2020-Q2010)/Q2010×100 | 待填 | NOT_RUN |
| 全省十年增长率 | (F2020-F2010)/F2010×100 | 待填 | NOT_RUN |
| 当年份额 | Q/F×100 | 两年分别填写 | NOT_RUN |
| 公报份额差 | 公报2020列值-2010列值 | 待填百分点 | NOT_RUN |
| 省内其余地区 | 各年F-Q | 两年分别填写 | NOT_RUN |

解释题：为何人口增加而份额下降可以并存？为什么不能把两端增长写成逐年持续增长？什么材料才能判断净迁移？请不要用上述算式代替成因证据。
