## 使用顺序

按编号从前向后使用，每项对应正文同号小节。遇到材料不足，留下具体缺口；不为填满表格补造日期、页码、人物或结果。

## 材料性质

真实文献题录与旧稿阅读范围分别标明。全文、选章、摘要和题录不能混用。另有虚构练习时单独标示，不将其当真实学术争论。

本组附件不含需安装依赖的程序。检索式中未执行者写为NOT_RUN；没有运行新检索、模型或复算，也未填写虚构命中数、正确率或耗时。
