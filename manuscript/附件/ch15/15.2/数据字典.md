# 第15.2节数据字典

所有id为本练习局部主键，不能跨节自动合并。source、evidence和locator均指教材虚构输入，不是档案号。null表示未知或不适用，0保留数值意义。

| 顶层字段 | 类型 | 内容 |
|---|---|---|
| `fiction` | bool | 约定或完整取值见input.json |
| `crs` | str | 约定或完整取值见input.json |
| `nodes` | list | 记录字段：`id`, `radius`, `x`, `y` |
| `edges` | list | 记录字段：`active`, `end`, `from`, `id`, `minutes`, `source`, `start`, `to` |
| `times` | list | 约定或完整取值见input.json |
| `sources` | list | 约定或完整取值见input.json |
| `threshold` | int | 约定或完整取值见input.json |
| `rectangles` | dict | 约定或完整取值见input.json |

坐标与时间的具体语义在正文和input.json中声明。14.1为两端包含的名称有效年；14.4为左闭右开的边界与事件区间；15章的事件窗口两端包含。米制教学平面没有EPSG代码，不能导入地球底图充当实测。start/end在不同对象上只限定该对象的有效性，不是文献成书年。known_at是研究库可知截点；covered与opportunities分别表示覆盖状态和检查工作量。

输入中的status为人工判断，输出中的status为程序规则处置，两者不得互换。数值输出为null时必须同时查对应原因，不把空值算零。列表型候选没有默认概率；来源依赖计数不是可信度分值。
