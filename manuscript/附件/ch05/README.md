# 研究问题知识库练习

本版新制教材配套。真实来源的整理值、教学设例、空白模板分开标记。代码状态 NOT_RUN，未作本轮学术复算或语言校对；文件结构检查不代表计算结果通过。

本包与正文5.1—5.8配合。使用公开现代桥梁介绍练习组织资料；不是古桥年代的新考证。

1. 打开 [start_here.md](start_here.md)，选择Q01或Q03。
2. 读 [sources.csv](sources.csv)，注意“页面记载”和“古代事实”不同。
3. 阅读 [N01交通比较](N01_transport.md) 与 [N02年代差异](N02_dates.md)。
4. 用 [问题卡](question_card_template.md) 与 [迁移表](migration_template.csv)组织自己的新材料。
5. 可在已有Python中执行 `python -B check_links_NOT_RUN.py`。脚本只查本目录Markdown的本地链接是否存在，不上网、不迁移、不删除、不改写。

[关系表](links.csv)记录研究关系，不当成历史人物关系。 [演示输入](input_manifest.csv)中的未取得古籍和来源不明图像只是迁移练习对象，状态不得写成已入库。

读者完成后应能从N02返回S02、S04，解释为何还不能选择年份；也能说明下一份材料必须有什么版本与位置。判断标准不是笔记数量或图谱大小。
