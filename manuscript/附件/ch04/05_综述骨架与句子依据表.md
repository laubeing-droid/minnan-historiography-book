# 综述骨架与句子依据表

对应正文4.5。此表解释正文完整综述段如何形成，不用它代替阅读全文。

## 段落骨架

1. 限定比较问题：沿海地方社会的外部联系怎样进入具体活动。
2. 比较文化接触与实践流动：保留Clark和Dean在时期、地域、对象上的差异。
3. 加入制度与家庭安排：只按已读的Szonyi导论说明问题安排。
4. 提出读者综合：把联系落实到行动与材料，不宣布三位作者拥有共同结论。
5. 形成后续要求：选择可比时期与活动，补参与资格、资源转移和记录形成材料。
