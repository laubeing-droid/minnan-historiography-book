# 配套文档的精选方法来源

## 本轮没有做的事

没有穷尽全书引文，没有复核全部作者观点的经验基础，没有把姊妹语料库的书目完整搬入本书，也没有将文献可检索当作其结论已正确。后续新引用应标明版本、具体用途和核读范围，避免从一个相关标题推演整套论证。
