# 教学与自学活动指南

本指南使用现有正文和配套，不新增伪史料，不要求部署系统。活动是教学建议，不是已经开课或验证成效的记录。当前可进行阅读、材料辨析和设计讨论；复算和独立校对仍待另行恢复。

## 四个可以独立开展的活动

### 活动一：从兴趣改成研究问题

读第1—4章，选择一个地方文化现象，写出对象、范围、待解释变化和两种竞争解释。使用第1章对象表及第2章相关附件，不以题目宏大作为质量标准。交付一页问题卡和需要寻找的材料，而不是先写一篇结论完整的文章。

讨论重点：问题是否可回答，材料是否对应问题，什么证据可能迫使作者改观点。

### 活动二：把一条记录拆成可核的判断

读第7章和第16章，从现有教学陈述中选一条，区分原文陈述、整理者身份判断、关系纳入决定及分析假设。保留无法判断的位置。交付一条来源回查路径和一个可能导致误并的反例。

讨论重点：两条材料是否独立，名字一样是否代表同一人，资料形成时间是否被当成事件时间。

### 活动三：分析一个“漂亮结果”为什么可能无效

从第12章的序列、第14—15章的空间材料或第17章网络中选一种。只读输入与规则，找出一个足以改变结果含义的条件，例如缺失被当零、时期边界错用、投影关系被误认为真实交往。交付问题说明和应补的证据，不要求现场运行。

讨论重点：技术输出与历史解释之间还缺哪一步，反例能否定位到具体材料。

### 活动四：人机分工与公开研究说明

读第19—23章，为前三项活动设计AI能做和不能替人决定的步骤。交付AI参与说明、来源边界和一个更正方案。AI可以提出候选，不要求学生接受它的观点；使用与否都可以，只需说明方法。

## 评价看什么

评价问题清楚程度、证据对应、比较设计、限制表述和修改理由。代码行数、提示词长度、生成字数和图形美观不是这些能力的替代指标。对同一材料出现不同解释时，比较依据与推论，而不是以模型投票决定胜负。

教学设例可以训练判断，不应被引用为真实闽南史实。若改用真实材料，先确定来源、权属和公开范围；不要要求学生把家庭或田野隐私提交到公开仓库。
