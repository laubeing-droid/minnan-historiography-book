# 阅读核查与后续复核指南

检查书稿时，最好先说清楚正在检查哪一种问题。文件能打开、程序能运行、数字能够重算、史料足以支持解释，各有不同的依据。把这些分开记录，才能知道后续还需要谁做什么。

已有教学代码检查见[执行审计](CODE_EXECUTION_AUDIT.md)。第20章的公开人口案例已获单独授权完成有限核读与复算，范围见[案例来源检查](../chapters/ch20/SOURCE_REVIEW.md)。这不是全书正式复算或独立学术校对的恢复。本页给出各类检查的组织办法，不把已做的教学检查、案例自查和后续独立复核混称。

## 平时维护先查什么

文档维护可以先检查路径、正文与附件的对应、材料身份、版本是否混接，以及新增内容是否含私人信息。发现错误后记录位置和影响范围。例如，修好一个链接只改变访问入口，不应同时把整章标成已经复核。

## 不同环节分别留下依据

|环节|检查内容|应留下的记录|
|---|---|---|
|史料核读|转写、引文、页位、版本、转抄关系|原件位置与逐项核读记录|
|方法适用|观察单位、缺失、切分、尺度和时间口径|使用条件及不适用情况|
|程序复算|实际输入、版本、依赖、输出与正文对照|真实运行记录与差异说明|
|论证复核|材料能否支持结论、是否处理竞争解释|按具体主张定位的意见|
|语言校对|术语、公式、图表和跨章指向|可追踪的修改，不覆盖平行版本|

发现问题后，要判断是来源不支持、统计口径改变、程序行为错误、展示错误，还是材料仍然缺失。原因不同，处理办法也不同。把所有问题统称为“幻觉”，往往反而说不清应该修改什么。

## 怎样处理独立复核和更正

参与写作或计算的人可以先做自查。独立复核还需要说明核查者及实际范围，不能因为进行了第二遍检查就自动取得独立性。存在分歧时，保留双方依据和未解决的问题。

修改后，先核对受影响的主张和输出，再判断是否需要扩大范围。一个局部错误未必要求全部重做，但改变观察单位或数据口径时，也不能只改一处数字而不检查后续解释。除第20章已明确授权的限定案例外，扩大正式复算与独立学术校对范围，仍由作者另行安排并记录。

## 史料的独立性与独立复核不是一回事

史料独立性问的是：几份材料是否出自不同的观察和记录过程？三个网站转载同一份普查公报，不是三份独立证据；不同公报引用同一次普查，也要说明共同的数据来源。核读时应追查原始发布者、调查批次、转抄和汇总关系，再判断交叉印证的力量。

独立复核问的是：谁重新检查了什么？程序复跑、作者自查和另一位研究者逐项核对原件，是不同工作。第20章已有另一位未参与原案例写作与计算的AI核查者，对关键人口数字、定义和有限结论作独立核查，范围见[补证与核查报告](../chapters/ch20/results/2026-11-12-followup/REPORT.md)。这不等于人类专家审校，也不覆盖所有相关史料。全书23章156节的文风与逻辑通读同样不等于全书引文和史料均已独立核验。
