# 阅读核查与后续复核指南

当前复算与校对仍暂停。本页是将来恢复工作的检查表，不是启动命令或已经通过的报告。

## 文档维护可先做的事

核对路径是否存在、正文与附件入口是否对应、材料身份是否一致、两版是否混接、新增内容是否含私人信息。此类检查不执行教材代码，不重新计算章内数字，也不作语言校对或史学验收。

## 恢复后分开记录

|环节|应当检查|交付证据|
|---|---|---|
|史料核读|转写、引文、页位、版本、转抄关系|原件位置与逐项核读记录|
|方法适用|观察单位、缺失、切分、尺度和时间口径|明确的条件与不适用情形|
|程序复算|实际输入、版本、依赖、输出与正文对照|真实运行记录，不回填成功日志|
|论证复核|结论能否由材料支持、竞争解释是否处理|按主张定位的审读意见|
|语言校对|术语、公式、图表和跨章指向|可追踪修改，不覆写平行版本|

错误分开处理：来源不支持、统计口径改变、程序行为错误、展示或链接错误、尚缺材料。不要把每一项都写成“幻觉”，也不要用一次运行成功掩盖解释不足。

## 独立性与更正

参与写作或计算者的自查不自动成为独立复核。记录复核者的实际贡献与核查范围，保留未解决分歧。改动后只对受影响主张安排复核，不无差别重启全部工程。复算与校对的恢复需要作者另行安排。
