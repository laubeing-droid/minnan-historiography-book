# 写作与研究方法

本书以区域历史学、文化地理与史料批判为研究依据，将计算工具放入问题、材料、比较和解释的具体环节。工程方式的意义是让材料和操作可接续，不是给历史结论盖技术合格章。

## 从问题到研究交付

1. 定义问题、研究对象、地域与时间范围，写出竞争解释以及能够改变判断的材料。
2. 建立来源表：区分原始材料、转抄与研究文献，保留出处、页位和版本。不能把同源转引当成多项独立支持。
3. 整理观察单位和字段；分别记录缺失、歧义、估计及未判，不用零或模型补全掩盖未知。
4. 先做简单比较和基线，再判断是否需要时序、GIS、网络或生成式工具。历史材料不满足方法条件时，应缩小问题或更换方法，而不是强行连续化和量化。
5. 将模型输出作为待核结果，回查来源、比较替代设定，识别解释与预测的区别。
6. 由研究者形成论证，公开必要的材料依据、操作与不确定性，记录更正，使后来者能够接续。

本库现阶段保存了写作稿和教材配套，不因此宣称这一整套研究过程已经在真实闽南史料上完成验证。

## 本轮编辑原则

写作主线为`manuscript/`，只在授权范围作有记录的修订；`round1_review/`为独立平行版，不拼接。`variants/`、`plans/`与`handover/`作为历史证据原样保留。旧稿中的操作指令不自动成为当前任务。

概念和学术史约10%、史料与方法及完整案例约75%、人的判断与风险反思约15%，是写作规划。章节数、篇幅和比例不代表质量验收。计算程序未运行时保留NOT_RUN / NOT_EXECUTED，当前不恢复复算与校对。
