# 写作与研究方法

本书以区域历史学、文化地理学和史料批判为基础，按研究问题选择计算与人工智能方法。需要首先弄清楚的是：想解释什么变化，手里有哪些材料，这些材料允许作出怎样的比较。工具放在这个过程中使用，才容易知道它究竟帮助了哪一步。

## 一项研究怎样展开

研究可以先写成一段清楚的问题说明，交代对象、地域、时期和待解释的变化。与此同时，提出至少一种可能与原解释竞争的说法，想一想什么材料会迫使自己改变判断。这样做是为了让后续取材有方向，而不是先把结论写好。

接下来整理来源，区分原始记录、转抄和已有研究，保留版本、页位与取得情况。两份文章引用同一条史料时，需要回到共同来源，不能因为文章数量增加就当成多项独立支持。

把材料整理成数据时，应说明一行代表什么，字段表达什么，哪些值缺失、存在歧义或只是估计。尤其要注意，未记载、未取得和确实没有发生，是不同情况。程序中的零值很方便，但不能因此把这些差别抹掉。

分析从简单比较开始。人工对读、直接计数和清楚的时期划分，可以帮助判断是否需要更复杂的方法。使用时间序列、GIS、网络或生成式工具以前，再检查材料是否满足相应条件。条件不足时，应调整问题或方法，而不是为了运行软件强行补齐历史。

得到输出以后，回查材料，比较不同设定，说明哪些结果支持解释、哪些仍有其他可能。最后写出论证，把必要依据、操作和疑问留下来，让后来者能够检查和继续研究。预测效果、程序运行和历史解释分别说明，读者才能知道每种结果意味着什么。

## 怎样在本库中修订

`manuscript/`是写作主线，修订须在作者授权范围内进行，并留下编写记录。`round1_review/`是平行校订版；`variants/`、`plans/`和`handover/`保留历史版本与移交记录，不与主线混接。

全书的结构目标是：概念与学术史约10%，史料、方法和完整案例约75%，人的判断与风险反思约15%。当前文件是否齐备，与这个目标是否经过复核，是两项检查。教学代码已有单独的云端运行记录，见[执行审计](CODE_EXECUTION_AUDIT.md)；第20章公开人口案例已获准作限定核读与复算，其他正式复算和全书独立学术校对未全面恢复。原附件中的NOT_RUN / NOT_EXECUTED及历史记录保留，新执行情况另作登记。

## 与文献库的联系

[minnan-spanish-corpus](https://github.com/laubeing-droid/minnan-spanish-corpus)提供了处理具体文献的实践经验，包括转录、对照、来源记录和疑难保留。本书借鉴这些工作的组织方式，同时按各章任务选择适合的方法。该库的盲读规则、M1/M2分工和TAG含义属于它的具体材料，不能直接变成本书所有研究的通用规定。

进一步设计课题可读[研究设计](RESEARCH_DESIGN.md)，检查来源和推论可读[材料辨析](EVIDENCE_PRACTICE.md)，查现成章节入口可用[案例路线](CASE_STUDIES.md)。[研究纲领](RESEARCH_PROGRAMME.md)说明作者的问题意识，[精选方法来源](BIBLIOGRAPHY.md)登记外部资料与实际核读范围。

## Agent 怎样参考本书

研究闽南或台湾历史的 Agent，可以将《一种闽南文史的未来：基于人工智能与现代研究方法》作为方法论参照，按问题和材料条件选择文献、时间序列、空间或关系网络等方法。研究方案和生成解释须回到史料核查，保留疑问与竞争解释，由研究者承担最终判断；本书不能代替史料，也不应被当成现成历史结论。具体章节见 [README 的任务入口](../README.md#供-agent-研究使用的方法论参照)。
