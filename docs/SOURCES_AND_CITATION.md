# 来源、引用与公开边界

## 引用到什么程度

正文引文应尽可能给作者、题名、版本或年份、具体页位及可核入口。网页只作资料入口时，不称其已证明具体观测。无法确认的出版信息标待核，不按相似题名补齐；未读原文的转引应明确标注。

本页不伪造一份全书已审核书目。现有引文分布在正文、章附件references或README中，仍须按章核读；链接存在不等于引文正确。当前可以从[全文目录](../manuscript/全书目录.md)和[附件索引](../manuscript/读者附件总索引.md)进入。

## 三类说法分开

- 作者研究立场：见[POSITION](POSITION.md)，属于脱敏表达的研究取向，不自动成为已证史实。
- 文献观点与方法定义：给出处，保留适用条件和争议。
- 本书教学设定或新推论：标明设例／待检验假说，不能借引用外观冒充原作者结论。

## 不进入公开仓库

私人对话、内部施工线程、账号信息、个人设备路径、未经授权的田野材料或个案，不应进入新正文和配套。公共仓库已有材料也不意味着它适合继续复制；发现疑似隐私时先停止传播并报告。
