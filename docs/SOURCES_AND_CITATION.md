# 来源、引用与公开范围

引用的作用，是让读者能够找到依据，并看清原材料与本书判断之间的关系。正文中的重要引文，应尽量给出作者、题名、版本或年份、具体页位和可查入口。没有读到原文而使用转引时，应说明转引来自哪里；出版信息不能确认，就保留待核，不能照着相似题名补齐。

现有引文分布在正文和各章附件的references或README中。可以从[全书目录](../manuscript/全书目录.md)与[附件索引](../manuscript/读者附件总索引.md)查找。全书引文尚未逐项审校，配套采用的部分方法文献另列在[精选来源](BIBLIOGRAPHY.md)，注明了读到全文、摘要还是题录。

## 让读者分清是谁的判断

作者的研究立场见[POSITION.md](POSITION.md)。引用这类内容时，应说明它是本书提出的观点。转述外部研究，要保留原来的条件、范围和争议；本书由此提出新的推论，也要让读者看见从原研究走到新判断的那一步。

教学设例用来解释方法，可以作为教学设计引用，但不能变成真实历史观测。网页只提供检索线索时，也应继续寻找支持具体史实的材料。写作稿的版本引用格式和贡献说明，见[CITATION_AND_CREDIT.md](CITATION_AND_CREDIT.md)。

## 什么可以公开

新正文和配套只收录适合公开的内容。私人对话、内部工作线程、账号信息、个人设备路径，以及未经授权的田野材料或个案，不应上传。发现已有文件可能涉及隐私时，应先停止继续传播并向维护者报告。

本库采用CC BY-NC-SA 4.0。第三方材料仍按其自身的权利和引用条件使用；仓库许可不能替馆藏机构或其他作者重新许可原件。不能直接公开的材料，可以在合法范围内保留题录、取得状态和访问说明，让读者知道相关依据存在以及目前能读到什么。
