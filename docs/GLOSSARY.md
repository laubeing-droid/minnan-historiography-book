# 阅读术语

|术语|本库用法|
|---|---|
|写作主线|manuscript的正文及其配套；经作者授权可有记录地修订|
|平行校订版|round1_review保留的另一版本；不自动覆盖主线|
|历史底稿|variants、plans、handover中保存的版本、方案与快照|
|新制教学件|依据方法或给定条件重新编制的说明、数据或程序；不是失落原件|
|NOT_RUN / NOT_EXECUTED|该材料对应执行尚未进行；不暗示通过或失败|
|结构检查|路径、文件对应、标记等检查；不等于数值复算或学术复核|
|来源收敛|围绕具体问题整理来源、识别转抄和重复，说明可用材料范围；不是把不同说法强行合一|
|独立复核|对明确范围由独立核查形成记录；自查不能自动替代|
|结构目标|23章156节、约35万字、10/75/15比例等写作安排；不是验收结果|
|研究工程方式|将来源、整理、比较、判断与交接组织成可持续过程；不把历史判断还原为程序输出|
