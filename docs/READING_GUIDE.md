# 读者使用指南

《一种闽南文史的未来：基于人工智能与现代研究方法》面向具有本科阅读能力而不限专业的读者。阅读时可以先理解问题和材料，再决定是否进入代码部分。已有技术基础的读者，也需要看清史料条件以后再选择方法。

## 按自己的需要选择读法

如果想先了解全书，可以从第1—4章的对象、问题和文献工作开始，再读第7—8章的数据与基线。之后选择时间、空间或网络分析中的一条路线，最后读第20—23章，看看分析结果怎样进入论证，以及人的判断承担什么作用。代码可以暂时跳过，示例的材料条件仍应读清楚。

如果手上已经有一批材料，可以先看第5—7章，明确资料怎样组织、字段怎样解释，再到第9—17章选择合适的方法。一个课题不需要把文本、视觉、时序、GIS和网络分析全部做一遍；只用其中一种，也可能回答好一个问题。

如果准备与别人合作，先读第18—19章，再回到实际材料，用小范围共同试做检查词义、字段和判断标准是否一致。形成分析以后，可用第20—21章组织论证和审读。

如果主要关心AI与文化，可以从[研究立场](POSITION.md)、[研究纲领](RESEARCH_PROGRAMME.md)和第22—23章入手，再回看一组具体方法章节。这样比较容易理解，关于文化和知识的思考，怎样与材料整理、分析和解释联系起来。

## 使用程序和报告问题

开始操作前先读本章附件README，确认输入、字段、依赖和输出位置。已有云端教学运行记录可供参考，但不能据此认定任意新数据都能使用同样方法。第20章公开人口案例已获准作限定核读与复算，其他正式复算和全书独立学术校对未全面恢复；后续开展这类工作时需另行安排。

遇到问题时，请给出章、节和文件位置，说明是链接打不开、字段不清楚、程序结果不符，还是某个论证缺少依据。程序问题可附不含身份信息的最小示例，不必上传私人材料。具体格式见[贡献指南](../CONTRIBUTING.md)。

引用时注明实际使用的提交版本、章节、位置和访问日期，并写明是写作稿。格式示例见[引用与贡献说明](CITATION_AND_CREDIT.md)。
