# 读者使用指南

本书面向本科及以上、不限专业的读者。不会编程不妨碍理解问题与材料，已有技术基础也不应跳过史料条件。本库是写作期材料，不要求读者安装一个统一工作台。

## 选择一种读法

**先理解全书。**从第1—4章看对象、问题和文献工作，读第7—8章的数据与基线，再选时间、空间或网络的一条方法线，最后读第20—23章的论证、核查和人的判断。可以暂时跳过代码，但不要跳过示例的前提。

**手上已有材料。**先用第5—7章辨认资料如何组织、字段如何解释，然后在第9—17章选择与研究问题相符的任务。不是每个课题都要做文本、视觉、时序、GIS和网络分析。

**想建立合作流程。**先读第18—19章，再回到实际材料章，用小范围共同试做发现词义、字段和标准不一致。最终用第20—21章组织论证与审读。

**主要关心AI与文化。**可先读第22—23章及[研究纲领](RESEARCH_PROGRAMME.md)，但应再看一组具体方法章节，理解理论反思如何落到材料和判断，而非只讨论宏观立场。

## 在仓库里找什么

- [全书目录](../manuscript/全书目录.md)：以章文件为阅读与引用入口。
- [全书合订](../manuscript/正文/全书合订.md)：方便连续阅读；与分章是同一主线，不重复计数。
- [读者附件索引](../manuscript/读者附件总索引.md)：找到本章输入、模板、脚本及说明。
- [当前缺件](MISSING_ITEMS.md)：判断某项“缺失”是旧原件未取得，还是当前教材操作材料真的不存在。
- [材料与状态](DATA_AND_STATUS.md)：理解新制件、设例、模板和NOT_RUN等标记。

首轮校订平行版不是主线的自动补丁。读者比较两版时应说明各自版本、位置与差异，不把喜欢的段落拼成未声明的“终稿”。

## 看见命令行或错误怎么办

当前复算与校对暂停，仓库中的命令是教材说明而非本次任务的执行要求。可以先阅读输入、字段和预期输出设计。将来另行运行时，遵守对应章README，不用任意新数据覆盖教学输入。

报告问题时给章、节、文件和可定位的小段原文，说明遇到的是打不开、字段不明、结果不符还是论证问题。不要上传私人材料来证明问题；可提供不含身份信息的最小示例。具体格式见[贡献指南](../CONTRIBUTING.md)。

## 怎样引用这本未完成的书

引用实际使用的提交版本、章节和位置，并说明是写作稿。不要以文件的保存日期暗示已出版或经过同行评审。规范示例见[引用与贡献披露](CITATION_AND_CREDIT.md)。
