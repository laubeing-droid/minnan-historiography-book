# 材料身份与状态登记

各章处理的材料不同，CSV、JSON、文本和代码都要结合本章数据字典阅读。同名字段也可能承担不同作用，跨章使用前应先核对含义。下面说明全书共同需要区分的材料身份和工作状态。

## 先确认材料是什么

|身份|含义|不得替代|
|---|---|---|
|真实来源|可定位的馆藏、史料或文献|不等于其中每个数字已核读|
|整理与判断|对材料的转写、归类、消歧、推论|不等于原文直接陈述|
|教学设例|人为构造或按给定条件重编的材料|不是真实观测|
|模板|等待填写的结构|空表不是完成结果|
|运行产物|指定输入与版本下实际生成的输出|不是史实真实性证明|

## 分别记录各项工作做到哪里

- 写作：未写／草稿／修订稿；未独立复核不称终稿。
- 原件：已取得／仅有引用／受限未读／待取回。
- 配套：原件／新制教学件／模板，分别说明来源。
- 执行：保留实际NOT_RUN或NOT_EXECUTED；有运行记录后才能记录通过或失败，且限定输入、版本和检查范围。
- 学术复核：未复核／存在待查／复核记录可定位；不得由执行状态自动推导。

新增配套时，记录路径、材料身份、依据、对应章节、未完成步骤和修订日期。目录清点只统计实文件，合订副本、历史版本、未取回引用不重复算正文或附件成果。当前盘面对照见[MISSING_ITEMS](MISSING_ITEMS.md)。

文献之间是否独立，另查它们是否转抄、共用调查或汇总同一数据；不能按网页或文件数量计算独立证据份数。另一位核查者是否完成独立复核，则需要单列核查者、范围和记录。第20章的另一AI核查者已对关键数字、定义及有限结论作限定核查，见[补证报告](../chapters/ch20/results/2026-11-12-followup/REPORT.md)；不将其写成人类专家审校或全书验收。
