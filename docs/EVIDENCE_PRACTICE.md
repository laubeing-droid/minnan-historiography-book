# 材料辨析、来源连接与判断记录

阅读一项材料时，需要分清原件说了什么、整理者做过什么处理，以及自己的解释还需要哪些证据。本页说明怎样把这些关系记录下来，方便回查。

## 一、看清材料怎样来到我们面前

一件材料在形成、保存和数字化过程中可能经历不同选择。研究者应分别说明材料原来为何形成、后来怎样留存、今天看到的数字副本怎样取得和处理。DARIAH的史料批判教学资源明确将数字化带来的变换纳入考察。本库据此要求把转录、裁切、标准化和模型改写等必要步骤说明白，而不是默认电子文本与原件完全等同。[DARIAH教学资源](https://campus.dariah.eu/resources/external/from-the-archival-to-the-digital-turn-a-lesson-on-source-criticism)

数字化并不是史学第一次出现有组织的资料工作；官修地方志、私人著述和既有学术编辑都各有生产与保存机制。新的工具改变工作条件，不抹去这些历史制度。

## 二、把不确定的地方说具体

|问题|适合怎样记录|不应怎样处理|
|---|---|---|
|字形看不清|原位置、候选读法、难辨原因|选最顺的一种后删除痕迹|
|身份待定|候选实体、支持与反证|按相似名字自动合并|
|日期精度不足|原文时间、精度、可支持范围|补成精确日期再排序|
|关系解释有争议|原陈述、解释、竞争解释|把推论写成直接引文|
|材料未取得|引用来源和缺失状态|用生成内容替代字节|

TEI对编码不确定、数值精度、转写难辨和事实断言作了区分。本库借鉴的是这种辨析，不要求把所有章改成TEI XML，更不要求把每种疑问编成概率。[TEI确定性、精度与责任](https://www.tei-c.org/release/doc/tei-p5-doc/en/html/CE.html)

## 三、一条结论怎样回到材料

可按“结论→整理判断→材料片段→来源版本与位置”登记。若使用了计算，再补输入、处理步骤和输出的对应。W3C PROV把实体、活动、参与者及派生关系分开，适合帮助理解这一联系；普通表格只要能够表达必要关系，也可以完成当前课题的记录。[PROV Primer](https://www.w3.org/TR/2013/NOTE-prov-primer-20130430/)

这条链能说明结论怎样产生，却不自动保证每一步正确。真实来源可能被误读，准确转录也可能被过度概括。对有争议的主张，应指出需要回查的是哪个环节，而不只说“有出处”。

## 四、材料选择影响能够推广到哪里

文献语种、体裁、年代、保存与数字化机会都可能影响观察。只在一种资料上得到的效果，不能直接宣称覆盖所有闽南历史文本。Bender与Friedman提出数据声明，是为了让数据背景及研究推广范围更加清楚；本书把这一要求落实为可读的来源与范围说明，而非固定格式认证。[Data Statements](https://aclanthology.org/Q18-1041/)

同样，少数来源保存充分的地方不能自然代表整个区域。没有记录也不能一律解释成没有活动。资料机会既可以成为控制条件，也可能成为研究对象，但必须说明采用哪一种解释。

## 五、让分歧可以继续研究

分歧记录应保留位置、分歧内容、双方依据、暂定处理和待补材料。不能为使数据整齐而强行一致，也不能只写“待考”而不说明下一步。具体可复制的简表见[研究记录模板](STUDY_RECORDS.md)。
