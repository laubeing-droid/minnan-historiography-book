# 项目意义：一种可以接续的闽南文史研究方式

本书要回答的不是“AI能替我们写多少文字”，而是：当识别、检索、比对和生成的成本下降之后，闽南文史研究应怎样组织，才能把材料真正变成可讨论、可检查、可积累的知识？

## 一、研究对象不缩成地方文化符号

本书把闽南看作在具体地理、生产生活和制度关系中持续形成的历史社会。语言、器物、仪式、建筑和文献都重要，但研究不能停在标志性景观或名人事迹。需要看普通人如何谋生、迁移、合作、冲突和传承经验，哪些变化具有长时段影响，哪些群体的经验没有进入主流叙述。

这是作者的研究取向，而不是规定所有研究只能得出一种结论。农业与自然环境是重要底层条件，海洋联系、贸易和迁徙的作用则应放在具体时期与材料中分析。地域名称不能代替观察范围，同一个结论不能从一个村落、一个港口或一座城市直接推到整个闽南。

## 二、从数字化进入研究，而不是停在校字

原件保存、转录和校字解决“有什么材料、读到了什么”的问题；历史研究还要回答“为什么问这个问题、材料能够支持什么、不同解释怎样竞争”。一批高质量电子文本是必要基础，却不能单凭数量宣布研究完成。

本书把工作连成一条可往返的路径：问题形成、材料选择、来源辨析、结构化整理、比较分析、解释与反例、公开写作。新证据可以要求回头修改问题，方法不适用可以要求缩小结论。工程方式的价值在于把这些决定留下，让后来者知道从哪里继续，而不是把流程锁成只能向前的机器。

## 三、为什么计算与生成值得进入地方文史

计算能帮助处理大量材料、检查重复和关系、比较时间与空间分布；生成式工具可以协助提出检索线索、候选分类和竞争解释。它们使原先难以承担的材料工作有可能开展，但“能够算”并不保证“值得问”，流畅的解释也不等于证据充分。

本书因此把工具放在研究任务内，而不按产品清单写作：选择模型之前先确定输出要解决什么问题，评价之前先确定错误会造成什么历史误读。工具可以更换，材料与判断的责任不能随工具一同消失。

文本可搜索性本身也会改变研究者看见的范围。Putnam关于数字化与跨国研究的讨论，提示便利的检索并不等于资料世界的全面呈现；本书据此强调保存未数字化、未命中和暂未取得材料的边界，而不是把搜到的内容当作全部历史。[Putnam工作论文记录](https://d-scholarship.pitt.edu/concern/generic_works/4cb2afde-40e8-42c6-8cfb-c5200a239fac)

## 四、工程方式服务史学判断

可接续的研究至少让五件事清楚：材料出处、整理规则、方法条件、未决问题和人的判断。它可以采用普通表格、Markdown和已有工具，不要求每个课题建设复杂平台。没有实际需要时，不增加环节和依赖；必要的工作不能因为自动化不方便而省略。

本书不把历史研究搬进法律形式化框架。史料残缺、解释竞争和价值判断并不总能化成封闭的真假命题。形式检查适合发现字段、日期和路径问题，无法独立决定历史意义。研究者仍负责议题设定、证据最终采纳、价值判断与解释。

## 五、书稿与语料库分别贡献什么

姊妹库[minnan-spanish-corpus](https://github.com/laubeing-droid/minnan-spanish-corpus)处理特定文献的转录、对照与整理问题，是材料工程的一项具体实践。本书讨论的范围更广：这些材料如何进入研究问题，怎样与其他来源比较，如何选择方法并写成论证。

语料库不是本书全部史料的总库，本书也不把其某次工程状态当作学术证明。两者可以共享来源意识、歧义保留与接续方法，但不照搬数据标签、验收门槛和计数。

## 六、当前贡献与尚待实现的目标

当前仓库已有23章写作稿、分章教学配套、平行校订记录、历史版本和方法说明。它提供了可供读者阅读、批评和继续开发的基础；部分附件仍未运行，旧原件仍有缺失，复算与独立校对保持暂停。

完整研究流程在真实闽南材料上的成效，仍需逐个课题检验。项目的目标是建立人借助AI持续研究的工作方式，不是用生成文字取代地方经验，也不是宣布已经掌握一套能够自动解释闽南历史的系统。
