# 文档总导航

本书完整题名：《一种闽南文史的未来：基于人工智能与现代研究方法》。

这套配套文档服务于“怎样完成一项可核的闽南历史研究”，不是把书稿改写成软件操作手册。中文为当前基准；正文、研究建议、历史档案与运行结果各有位置。

## 不需要一次读完全部文档

一般读者先读阅读指南和相关正文即可。研究者在确定问题后选用记录卡，贡献者在修改前阅读维护和来源规则。已有可靠记录可直接引用，不要求为每个小问题重复建立一整套表格。

第20章公开人口案例已获准作限定核读与复算，其他正式复算和全书独立学术校对未全面恢复。文档中涉及的运行、教学与研究方案是说明和建议，不自动授权执行；历史NOT_RUN / NOT_EXECUTED记录保留，后续执行结果另按输入与版本登记。所有新增文档沿用[CC BY-NC-SA 4.0](../LICENSE)。
