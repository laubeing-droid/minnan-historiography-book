## 2. 四地专题报告

### 2.1 厦门（专题一·鼓浪屿景区化与"小资城市"生成）

**制度链（已验证）**：1988国家级风景名胜区 → 1993人口"只准出不准进" → 1994–2000工厂外迁约5亿 → 2000.3最后工业烟囱爆破 → 2002"音乐之岛"+《发展概念规划》定位风景旅游区 → 2003.10撤区设管委会 → 2004总规人口裁1.2–1.5万 → 2005《管理办法》 → 2007 5A → 2008申遗启动+文化营销 → 2012预备名单 → 2017.7 UNESCO列入 → 2019《保护条例》 → 2020综合执法。

**人口与社区（已验证）**：2010普查户籍居民6800+空挂7100；2013常住约1.4万、原住民约8000；常住人口1993后年均递减约3.16%；六普老龄化19.79%（全市6.93%）。学术研究（赵晨西2021；"权力视角"学位论文；2017《地理与地理信息科学》）一致指认原住民在旅游空间生产中权能弱化、"异化危机"。

**"小资/文艺"形象（部分验证）**：已证2002"音乐之岛"、2007前后"万国建筑/钢琴之岛"媒体表述、2008前后自媒体回溯"小清新之城"、2019后官方"文艺之城"。**缺口**："小资"一词最早见媒时间未定（检索词见C）。

**作为先例（已验证）**：福建省文旅厅2022-04-21答复逐字"指导泉州借鉴武夷山、福建土楼、鼓浪屿相关经验"——厦门经验成为泉漳后续景观化的制度文本先例，2024三市共建"世界遗产风景道"进一步联动。

**红队结论**：厦门完成了"居民社区→景区→世遗地"的全链条制度转化；原居民生活确被游客消费空间挤压（人口锐减、老龄化、公共服务外迁为硬证）；"小资城市"形象由官方营销+媒介叙事共建，但其"文艺/小清新"定性属价值宣传，不宜作为社会事实。

### 2.2 泉州（专题二·世界遗产、海丝叙事与历史样板化）

**申遗叙事演变（已验证）**：2001启动"海上丝绸之路：泉州史迹" → 2014"海丝泉州"品牌外推 → 2017单列 → 2018"发还待议" → 2020更名"泉州：宋元中国的世界海洋商贸中心"并增6点 → 2021.7.25 UNESCO列入（标准iv）→ 2023.4城市品牌logo。"宋元中国/海丝泉州/东方第一大港/多元文化/开放包容"为当代官方叙事关键词，非古代史自明。

**多主体角色（已验证）**：政府（申遗文本/品牌）、UNESCO（标准iv与OUV框架）、高校（厦大/研究平台）、媒体（人民网/泉州晚报）、文旅企业（演艺/旅拍）共同生产"海丝样板"。省政府2022要求"泉州借鉴鼓浪屿"印证城市间模板复制。

**前现代泉州港 vs 月港—马尼拉—白银体系（已验证）**：泉州港为宋元官办海洋商贸中心（10–14世纪）；明初海禁后市舶司1472/1474北移福州，贸易中心南移至月港；月港1567隆庆开关为法定私商港，以货币税饷为特征，承接1571–1815马尼拉大帆船贸易，美洲白银经此入华（中国社科网/中国新闻周刊/厦门周刊）。二者结构不同：官办/私商、奢侈品/日用品、阿拉伯—东南亚/日本—美洲，不可混同。

**蒲寿庚—亦思巴奚（外文+学术支撑，已验证）**：英文Wikipedia（引Brill EI2 Lin1995、Lo2012、Kuwabara1928）记蒲寿庚约1250任市舶提举、1276叛宋降元、家族于亦思巴奚兵乱(1357–1366)遭屠、明初禁仕；族源学界尚有占城/中亚说，未定阿拉伯。**缺口**：Encyclopaedia Iranica专条与Cambridge/Brill专著未直取（见C）。

**红队结论**：泉州世遗是当代城市叙事对一段前现代港口史的"样板化提升"，其价值由UNESCO标准iv与申遗文本框定；不得把"宋元海洋商贸中心"提升为整个闽南文化的总体本质，更不得以国内文旅材料倒推宋元穆斯林史（须以外文一手/学术二次文献为准）。

### 2.3 漳州（专题三·古城"盆景化"与后发赶超）

**制度链（已验证）**：1986国家名城 → 2001转向保存 → 2002.4.29省批详规 → 2004.9 UNESCO亚太奖 → 2005暂行规定 → 2010十大名街 → 2012浙江院策划 → 2013有机更新规划 → 2015一期征收不回迁+首批历史街区 → 2018"古城印象"沙龙(闽南师大) → 2018.7业态报告/拟设公司 → 2019漳台论坛 → 2021.10《保护条例》(53公顷) → 2022.7文旅康养接管 → 2023国家级休闲街区 → 2024.2清华同衡复兴规划(318万) → 2024.7专班 → 2024.10数字IP"侯喜" → 2025 AI剧本游/客流3730万(+31%) → 2026省文旅大会落地。

**人口与业态（已验证，口径需核）**：官方/媒体称核心区原住民1.7万、留存率超90%（2024省政府门户/闽南日报）；一期投资超40亿、立面3.74万㎡、修缮1.12万㎡。学术（2019《西南大学学报》Q方法）显示居民负面感知（原真性削弱）随商业化上升。**缺口**：1.7万与1.85万基数口径略异，独立住户追踪调查缺位。

**概念话语时间线（已验证）**："古城印象"2018闽南师大沙龙；"有机更新"2012–2013；"活态传承/烟火气"2024-05省政府门户密集出现；"网红打卡"2024-10；"数字IP/侯喜"2024-10；"剧本游/AI剧本游"2025国庆。

**后发赶超（须谨慎，已验证）**：时间上确为后发（客流爆发2024–2025、2026省文旅大会首次落地漳州）；但官方叙事明确定位"差异化"（活态/烟火气/原生态），与厦泉"世遗/海丝"基调不同。**不得把"眼红"当事实**；"模仿性"仅见政策时间/项目类型/投入变化的间接证据，隐性对标内部文件待查（见C）。

**红队结论**：漳州古城保留了较高原住民比例（待核口径），但"活态/烟火气"本身已成为被主动编排、用于游客观看的真实性资源（前厂后店、旅拍妆造、网红打卡点为硬证）。其景观化机制更接近"盆景化"——把生活选择性截取为可消费样本，而非整体社区存续。

**漳州沿海类似簪花实践（D级，非"不存在"）**：已证东山岛女性"头戴花/簪红花"婚嫁成年礼节庆习俗（CCTV《发现·探索》2006）；漳州纸头花"牌仔枝/春仔花"民俗与龙海新厝社制花史（闽南日报副刊2025）。待验证：方志是否载"头顶花园"式渔女簪花围、是否旅游化为古城旅拍爆款（目前仅见游客自发"簪花少女"妆造）。

### 2.4 台湾（专题六·网络化集中景观）

**社造—文创—地方创生链（已验证）**：1994文建会提"社区总体营造" → 1995"文化产业化、产业文化化"(陈其南) → 2002《挑战2008》文创十大 → 2008地方文化馆二期 → 2010《文创法》 → 2017国发会宣示"地方创生"、文化记忆库计划 → 2019地方创生元年+文策院(TAICCA) → 2021记忆库上线(270万笔、CC 52%)。

**国家文化记忆库（已验证）**：明确使用"知识图谱""台湾文化DNA(Diversity/Nearby/Advance)""智能化口述史""影视内容IP孵化器"等词；多节点整合（22县市+117民间+18部会+12博物馆）。**红队注**："台湾文化DNA"为品牌隐喻（多元/就近/进步），与南岛语族生物学古DNA无关，禁止混同。

**资源集中与格式趋同（框架已证，量化缺）**：补助采统一9类申请格式、三年上限（文化部要点）；社造—地方创生—青年行动在补助体系内串接；文策院为内容产业中介。但"通过率分布/产业集中度"缺量化数据（见C）。

**身份叙事 vs 闽南语/家庭/亲属异步（语言统计强）**：主计总处2020：6–14岁台语为主要语言仅7.4%、65+为65.9%；叶高华：1986–94出生家庭闽南语22.3% vs 华语57.3%；中研院：已婚有子女者仅33%与子女说闽南语。**影视作品仅作文化工业文本，须与语言统计/口述/家户结构互证**（本次未深入，待补）。

**南岛语族（一手，已验证）**：Nature 2021（王传超）台湾古人与大陆壮侗语人群遗传紧密；Cell/Nature 2020（付巧妹）奇和洞—亮岛—台湾遗传连续，源于大陆东南沿海；Cell Genomics 2025溯及长江流域农业人群。**古DNA仅证群体遗传连续，不构成现代政治身份结论**。

**红队结论**：台湾形成"多节点但格式趋同"的资源集中（补助格式+记忆库+文策院+地方创生会报），公共身份叙事与闽南语日常使用、家庭实践显著异步；数字化（知识图谱/AI/开放授权）把地方文化转为可计算样板，但技术实质与集中度量化仍待验证。

### 2.5 跨域专题一·簪花景观的脱域与全国复制（专题四）

- **原始情境（已验证）**：蟳埔女婚俗/妈祖巡香/渔女劳动中的头饰花；2008入国家级非遗。
- **旅拍起点（已验证）**：2023.1赵丽颖《上城士》大片引爆，体验馆由数家→150–200+家；2024店铺约200+、客单价约40元；2024接待超850万、2025超930万，带动消费18→20亿、周边70亿；抖音"簪花围"约300亿次。
- **官方叙事链（已验证，有反证）**：2017起媒体将簪花围/蚵壳厝对接"海丝/阿拉伯/中亚"；人民网/央视沿用"素馨花、含笑花来自阿拉伯"。**反方学术**（李国宏/李玉昆，2025《东方收藏》）：文献所见簪花围史料始于西汉陆贾《南越行纪》，属汉族古俗遗风，非阿拉伯传入。**二者均未成定论，属待验证主位线索，不得作古代史证据。**
- **非原始服饰组合（已验证）**：旅拍普遍混搭马面裙/旗袍/汉服/傣服（UGC），无历史依据。
- **全国复制（已验证）**：2024扩散至成都洛带（店铺涨5倍至120+、去年接待超100万、带动消费超1.4亿），与汉服/客家结合；漳州本地仅见游客自发"簪花少女"妆造，非本土习俗文旅化。

### 2.7 跨域专题三·闽南学建设与文化数据库化（专题七）

- **最早提出（已验证）**：2003第二届研讨会"闽南学正在产生"（中新社2003-09-16✓）；陈耕《闽南学学科体系理论框架初探》给独立学科定义。早于2003的命名待查。
- **定义演变（已验证）**：林华东2009"四特征/海洋文化为主要特征" → 2011"三圈说" → 2012陈耕"十个方面" → 2015陈支平"环闽台海洋经济文化圈" → 2024–2026"陆海兼容"核心特质、"全球/世界闽南文化圈"（陈支平2026）。
- **概念先于证据（红队质疑，已证）**："陆海兼容/文化圈"集中于2024–2026政策期，支撑性多重证据仅概括引用，系统证据汇编未附；"世界闽南文化圈"确切首现文本、"陆海兼容"最早文本待查。
- **资助/平台/数据库（已验证）**：2010专题库4.3T；2025厦漳泉三平台上线；鼓浪屿元宇宙+AIGC；闽南师大2026博士点论证会（批准状态待核）；入选"绝学"扶持计划（2026）。
- **治理机制空白（红队结论）**：检索到"碎片化"反思充分，但"证据宪法/材料准入规则/方法冲突裁决机制"未见专门文献——学科建设以"规划—立项—博士点—绝学"路径推进，方法层治理尚属空白，是《三部曲》可重点补白处。

## 4. "簪花增长—闽南语衰退"双指标分析

> 说明：两指标为**并行现象**，非已证因果。仅呈现可验证数据，不作"文旅繁荣导致语言衰退"之推论。

**簪花增长轴（泉州蟳埔，已验证）**
- 旅拍店：数家(2023初) → 150–200+(2023) → 近300家(2024–2025)
- 年游客：850万(2024) → 930万(2025)；带动消费18亿→20亿、周边70亿
- 平台声量：抖音"簪花围"约300亿次、小红书约42万篇
- 扩散：成都洛带店铺涨5倍(2024)

**闽南语衰退轴（四地，已验证）**
- 厦门：中小学生流利<15%
- 泉州：小学生地道40.13%；城市10岁以下方言为主仅17%
- 漳州：9–15岁自评52%；"不会讲普遍"(2023政协)
- 台湾：6–14岁台语主要7.4%；已婚有子女者仅33%与子女说

**观察**：在"非遗+旅拍+平台"把闽南文化符号（簪花）推至空前可见度的同期，闽南语作为日常实践性载体的代际传递持续走低。二者反向运动提示：景观化放大了**可观看的文化符号**，却未逆转**不可观看的日常语言实践**的萎缩。此反差本身即是"景观—认知坍缩"链条的经验征兆，但因果关系须以家户语言追踪+文旅投入的配对研究验证，不可直接断言。

## 7. 可供《闽南文史三部曲》使用的理论命题

1. **总链条命题**：活的地域实践经「景区化→盆景化→样板化→集中式景观控制→平台流量化→数据化与向量化」逐级转化为可观看、可消费、可复制、可计算的文化样板；末端是"景观—AI驱动的历史认知坍缩"。
2. **去语境化抽取命题**：样板化是对活态实践的"去语境化抽取"——把整体社区/习俗截取其可展示片段，重组为游客观看的真实性资源（漳州"前厂后店"、蟳埔旅拍即例）。
3. **制度先行命题**：景观化多由行政规划/立法/申遗文本启动（厦门管委会、漳州条例、泉州申遗、台湾社造），媒介与资本为放大而非起源。
4. **叙事升级命题**：城市品牌（"宋元中国""海丝""活态烟火气""台湾文化DNA"）由政策文本逐级固化，其价值定性不等于所指向的古代史。
5. **符号—实践背离命题**：景观化放大可观看符号（簪花），却不逆转不可观看的日常实践（闽南语）；二者反向运动是认知坍缩的经验征兆。
6. **数据库化命题**：非遗名录化+开放授权+知识图谱+AI 共同完成"可计算文化样板"；当"文化基因"成为标注字段，文化被转化为可检索向量，历史认知让位于推荐与生成。
7. **异步命题**：公共身份叙事与家庭实践、语言使用、亲属关系存在系统性异步（台湾语言统计为硬证）；以叙事覆盖实践会高估"传承"。
8. **概念先于证据命题**（闽南学）：学科核心特质（陆海兼容/世界文化圈）先于系统证据汇编进入定义，存在把规划当本质的风险。

## 8. 不得直接采用的宣传性结论清单

1. ❌ "泉州自古就是开放包容的海洋文明典范"——属当代官方叙事，非古代史自明；宋元穆斯林史含蒲寿庚叛降、亦思巴奚清洗等冲突面。
2. ❌ "漳州古城原住民留存率超90%=活态传承成功"——留存率口径未附（1.7万/1.85万基数差异），且"活态"本身可被编排为观看资源。
3. ❌ "蟳埔簪花围=宋元阿拉伯人遗留风俗"——学界有反证（李国宏/李玉昆：汉族古俗遗风），属待验证主位线索。
4. ❌ "闽南学'陆海兼容'是经验确证的本质属性"——概念集中于2024–2026政策期进入定义，系统证据未附，属概念先于证据。
5. ❌ "台湾文化DNA（D/N/A）=南岛语族生物学基因/两岸同根"——"DNA"为品牌隐喻（多元/就近/进步），与古DNA无关，禁止混同或政治引申。
6. ❌ "闽南语文化活动繁荣=日常使用回升"——四地活动↑与使用↓并存，反差主题已证，不可倒推。
7. ❌ "厦门'文艺之城/小清新'是最贴切的城市本质"——属主观营销判断，非社会事实。
8. ❌ "漳州是在'眼红'厦门泉州后模仿赶超"——无官方文本支撑，仅见政策时间/项目类型间接证据，须以内部文件验证。
9. ❌ "把局部港口史（宋元泉州/月港）提升为整个闽南文化的总体本质"——须区分不同体系，禁止以遗存并置推导历史和谐。
10. ❌ "古DNA证明现代政治身份/两岸归属"——古DNA仅证群体遗传连续，不构成当代政治身份结论。
