# 事件筛选标准：实际影响与研究价值双通道

版本2.0，2026-09-11。性质：本研究工程的编辑与判断规则，不是学界统一的量化重要性定律。

## 一、首先区分三个集合

**志书收录过的材料 ≠ 本研究需要使用的材料 ≠ 进入主时间线的事件。**

原文底库尽量完整；主时间线必须精选；专题研究允许重要的小事、失败和反例；序列观察保留状态与数量资料。筛选发生在解释与展示层，不在最初识读层删除原条目。

“水”不能作为程序字段。它必须拆成可核查的问题：这段记载是否只有活动发生，没有具体改变？是否只借用级别、宣传修辞、荣誉或“首次”证明自身重要？是否有一个不是随意附会的研究问题？若材料太短、尚不能判断，进入待核，不等于判定无价值。

历史意义的两条常用思路是后果与揭示力：一类事件产生深、广、持续的变化；一类看似普通的经历能够揭示较大的历史过程。[1] 本项目将二者拆成独立通道，避免重要性被官阶、篇幅和宣传资源替代。

## 二、实际历史影响：五个标准

| 标准 | 必须回答的问题 | 可用的材料锚点 | 不足以成立的说法 |
|---|---|---|---|
| 1. 影响深度 depth | 究竟改变了谁的生存、生计、生活、生产或行动能力？ | 严重死亡、流离、土地丧失、劳动转换、成本负担、持续供水、迁居、关键资源进入/退出 | “影响深远”“成绩显著”；只说开会、参观、揭牌 |
| 2. 相对范围 reach | 对当时的哪个地方、组织或群体而言影响显著？ | 受影响村落/行业/人群及其合理范围；有条件时提供分母 | 全国头衔、媒体热度、绝对人数大、领导级别高 |
| 3. 持续或不可逆 duration | 改变是否延续、反复、锁定后续选择或难以恢复？ | 规则多年沿用、河道永久改线、长期失地、组织解体或新生产方式持续运行 | “至今意义重大”；事件年代久远；把竣工等同长期奏效 |
| 4. 制度与配置 institution | 谁获得/失去何种资源、权利、负担、权力或执行能力？ | 已生效的新分配规则、赋役改变、土地处置、治理权限、实际执行的资格和责任变化 | 内部排班、一般办文细则、原则性要求、尚未实施的计划 |
| 5. 过程节点 process | 它在有材料支持的前后过程中处于何种关键位置？ | 开始/扩散/中断/终结，具体环节改变后续实践；有原文或独立补充材料 | 单纯先后相邻便称因果；“为后来奠定基础”；见到“首次”即推定转折 |

### 主时间线的可执行规则

先满足：**与本研究地域有关系；存在实际后果或生效规则；后果陈述能够回到材料。** 然后至少满足下列一路：

A. 明确的实质制度/资源配置变化；B. 极深后果，例如严重饥荒、死亡、流离，不要求还同时证明长期性；C. 明确的影响深度，加上有支持的相对范围、持续性或过程节点之一。

这些规则是防止泛泛晋级的默认编辑合同，不是从数学公式中推出历史真理。仅有片段存在，不等于片段真的证明了所述后果；程序验原文，研究者抽查解释。

### 尺度必须讲清

村级事件可以对某类群体具有很深影响；县域事件可以进入县域精选而不构成闽南区域转折。所谓“主时间线”首先是本研究的精选阅读层，不意味着每一条都有同样的区域重要性。

形成发表用的“闽南区域总编年”时，应再说明事件的影响单位和区域联系：跨县扩散、共同制度变化、关键节点，或具有明确解释力的代表性案例。不要靠把所有县域主条目机械相加，就声称得到一部区域通史。

## 三、研究价值：另有五个独立标准

| 标准 | 合格的研究理由 | 防止泛化的约束 |
|---|---|---|
| 6. 机制解释 mechanism | 一个小案件、小工程、小组织变化，能检验资源如何分配、成本由谁承担、制度如何实际运作 | 要写明“什么机制、涉及谁、待核什么”，而非“反映社会生活” |
| 7. 比较价值 comparison | 同类安排为何在不同县、年代、群体产生不同结果；同一事件何以记载不同 | 不编造对照方事实；比较单位、时间和资料口径需要明确 |
| 8. 失败、异常、反证 anomaly | 失败的技术、被撤回的方案、未出现预期变化、与主流解释相反的材料 | 不因未成功、不是主线、反对研究者假说而删除；失败不是自动重要，仍须具体问题 |
| 9. 序列观察 series | 可成为人口、价格、赋役、灾害、教育、流迁等连续观察的一个点 | 同口径先核；县界、单位和统计对象改变不能直接画成增长；空白不能填零 |
| 10. 记载与编纂 recording | 不同版本具体改名、改写、删载、移时、承袭或分类变化，能够研究记忆生产与编纂机制 | 仅称“可研究政治话语”不足以收尽所有会议；必须有可检验的差别或问题 |

研究通道必须同时有“具体问题”和“支持提出该问题的材料”，但不要求答案已经确定。原文只有潜在线索时存待核，补读后再进入专题研究。系列数据存“序列观察”，不冒充一件改变历史的行动。

## 四、六层分流及其含义

| 代码 / 中文 | 收什么 | 不意味着什么 |
|---|---|---|
| main / 主时间线 | 有具体影响或实质规则改变的精选事件 | 不自动意味着区域级重大转折，也不意味着逐条考证已完毕 |
| research / 专题研究 | 有机制、比较、反例或编纂等明确问题的材料 | 不等于已经证明该机制或理论 |
| series / 序列观察 | 状态、数量、显式否定观察 | 不等于口径已可比，更不是历史事件发生频度 |
| context / 区域背景 | 有关联的域外/上位背景，当地发生或影响尚未建立 | 不应复制成每个县都实际发生了一次 |
| archive / 仅底库 | 当前只有例行活动/荣誉/仪式，或没有实质影响和具体研究问题 | 不是“永远没用”，原文仍能检索、对读、复评 |
| review / 待核 | 影响或研究价值可能存在，但日期、识读、地点、支持关系或上下文不足 | 不等于不重要，也不是禁止进入其他工作流程 |

证据可读性和编辑入选是两回事。重要但冲突的事件进入待核时，其影响评价仍保留；不能因为证据不够清楚就在历史上判它没有意义。

## 五、默认降层的具体情形

例行会议、普通视察、访问接待、剪彩揭牌、常规授奖、无实践结果的纪念活动、一般机构换届、口号总结以及“首次”“最大”“填补空白”自证重要的条目，在没有可指认后果和研究问题时，只留底库。

**这些是内容判断，不是词语黑名单。** 会议真的改变用水负担、访问伴随明确政策实施、机构改组改变地方治理，仍按其具体后果入选。正面和负面、政府与民间、传统和现代事件使用相同标准。

不设“每县保留若干条”“每朝选十件”“删除80%”等配额；不奖励文字长、数字多、版本新。简短灾荒可能很重要；长篇会务未必值得主轴。

## 六、十个边界例子（全部为构造示例，不是史实）

| 构造条目 | 分流 | 理由 |
|---|---|---|
| 某领导莅县视察并作重要讲话 | 仅底库 | 仅证实活动，不假定实际改变 |
| 某次会议废除按户摊灌溉费，改按实际受益田亩征收，免除无田户负担 | 主时间线 | 名称虽为会议，实质是成本与负担重分配 |
| “大饥，道殣相望，民多流亡” | 主时间线 | 严重后果已经显现，不因没有精确人数、记录短而删除 |
| 数户佃农因修渠费用分担提起争议 | 专题研究 | 检验受益权、产权与劳动负担如何相互配置 |
| 新式水泵数月后停用，志书记载缺少维修材料 | 专题研究 | 失败有机制价值，不因非成功史而略去 |
| 首办旅游节，受表彰 | 仅底库 | 首次和荣誉不能自证实践改变 |
| 某街转为展示区，原居民迁出、共同灶房拆除且不得恢复居住 | 主时间线 | 具体居住与实践条件改变；不需要预先赞成或反对旅游 |
| 相邻两年人口大增，但其中一年并入邻乡 | 序列观察 | 保存数值与口径变化，不直接断言人口繁荣 |
| 一个时期明确记“全年无水灾” | 序列观察 | 显式负观察；区别未记载与没有发生 |
| 某地工业就业增加，同时共同灌溉组织持续运作 | 专题研究 | 可检验“工业化必然消灭旧组织”的工作假说，允许相反结论 |

## 七、防止“先筛选，把真正有价值的材料筛掉”

第一次筛选只能是暂定。跨书候选召回检索全部层，包括仅底库。两个本来普通的条目，对读后若出现实施差异、扩散链、文本异文或明确反例，比较模型可以提出恢复研究的理由；程序将其从仅底库转为待核，研究者再采用。

救回不是不加区别地抬升所有相似活动。相似只是查阅入口，不是真实性、同一性或重要性的证明。发生地点也不能由“出在哪本县志”反推。[3]

## 八、不可采用的四种判断方式

不能把“重要性×可信度×地方相关度”相乘成貌似客观的总分；不能以某一理论为答案模板；不能按相似度删除跨书原文；不能以更多志书相同记载自动推出更多独立证据。[3]

正确输出应是：“拟入专题研究，因为它提供了一个关于成本分担的具体问题；当前只凭甲志一条，是否实际执行尚待查本书水利篇。”这种有限而具体的结论比0.91分更有用。
