# 闽南文史 All in AI 三部曲项目 Handoff v0.1

## 项目名称

《闽南文史 All in AI》

三部曲：

1.  《闽南文化的灭亡》
2.  《闽南文史的灭亡》
3.  《闽南文史 All in AI》

------------------------------------------------------------------------

## 一、项目总目标

本项目不是传统意义上的地方文化保护项目。

核心问题：

> 在现代化、景观社会和人工智能数据化背景下，研究闽南文化如何逐渐脱离原有实践基础，并探索如何利用
> AI 工具，在不可逆的文化转型过程中保存历史材料、提升研究理性。

核心判断：

闽南文化的本质不是信息，而是闽南人在特定土地、生产方式和社会关系中的历史实践。

------------------------------------------------------------------------

# 第一部：《闽南文化的灭亡》

## 研究对象

闽南文化本身。

## 核心问题

一个建立于土地、生产方式和人的实践基础上的区域文明，如何逐渐失去存在条件？

## 四阶段：

### 第一阶段：土地与实践统一

自然环境 → 农业生产 → 社会关系 → 人的实践 → 文化形成。

### 第二阶段：现代化导致实践分离

文化从生活方式变成过去的对象。

### 第三阶段：景观社会

文化由参与变成观看。

### 第四阶段：人工智能数据化

实践 → 文本 → 数据 → 向量。

文化成为高维空间中的概率关系。

------------------------------------------------------------------------

# 第二部：《闽南文史的灭亡》

## 研究对象

闽南文史知识生产体系。

## 核心问题

为什么现代闽南文史逐渐失去理解闽南文明的能力？

## 四阶段：

### 第一阶段：地方实践中的知识生产

地方志、乡绅记录、家族文献。

### 第二阶段：学术对象化

闽南成为研究对象。

### 第三阶段：大众传播景观化

流量、标签、情绪替代理论和解释。

### 第四阶段：AI化前夜

大量内容提前呈现模板化、标签化、机器可复制特征。

------------------------------------------------------------------------

# 第三部：《闽南文史 All in AI》

## 核心问题

当文化和文史研究面临危机时，人如何利用 AI 保存最后的历史理性？

不是 AI 复兴闽南文化，而是：

保存材料、辅助研究、提升人的历史判断能力。

------------------------------------------------------------------------

## 第一部分：闽南文史知识库

目标：

建立个人研究基础设施。

内容：

-   地方志
-   学术论文
-   档案
-   族谱
-   图片
-   地图
-   口述资料

技术方向：

-   Zotero
-   Obsidian
-   RAG
-   Vector Database

------------------------------------------------------------------------

## 第二部分：AI辅助历史研究体系

AI作为研究助手，而非历史作者。

方向：

-   文献整理 Agent
-   史料分析 Agent
-   研究辅助 Agent
-   历史证据 Agent

参考：

-   Digital Humanities
-   Historical GIS
-   Research Agent
-   GraphRAG

------------------------------------------------------------------------

## 第三部分：理论重建

基于：

-   区域史学
-   地理文化学

研究：

自然环境、人口区划、区域制度、重大历史事件。

------------------------------------------------------------------------

## 《闽南通史》

定位：

未来开放成果。

不是当前任务。

应基于：

-   区域史学
-   地理文化学
-   历史过程分析

形成真正的区域文明史。

------------------------------------------------------------------------

# Codex执行目标

禁止：

1.  不直接生成《闽南通史》。
2.  不把闽南文化简单理解为海洋文化或民俗文化。
3.  不把 AI 描述为文化救世主。
4.  不脱离史料。

最终交付：

1.  《闽南文史 All in AI 项目研究报告》
2.  闽南文史个人知识库方案
3.  AI辅助历史研究 Agent Skill 方案
4.  理论论文框架
5.  未来《闽南通史》草稿基础
