# 《一种闽南文史的未来》通用研究方法详细目录候选

本目录以闽南文史为适用领域，以通用 AI 研究方法为主体；相关方法可供区域历史学与文化地理学中的不同课题复用，不按个人专题分章。研究对象、证据结构、时间尺度、空间尺度和解释问题决定方法的适配条件，不预设贯穿全书的个人项目或地方个案。研究者先确定问题和可用证据，再选择文本、视觉、时序、空间或网络方法；并非每项研究都要使用全部技术。

本次只提出目录，不写全书，不替换旧稿。当前归为 **7 编 23 章、152 个技术小节**，这是内容归并的结果，不是预定的篇幅指标。各章按实际技术与研究问题设独立小节，不限制为四节；每个知识点的讲法才按“定义、任务与成果 → 输入数据与选择条件 → 具体操作顺序 → 结果评价与改进”展开。最后两章保留研究思考的论证性质，其操作是比较、审查和形成判断，不伪装成模型训练步骤。

以下“定义与成果、输入与选择、操作顺序、评价与改进”四个字段属于各技术小节的写作说明，不是成书正文。本目录仍是候选，不是新正文或新书定稿，也不表示全部章节已经获准写作。

## 主骨架

1. **明确研究对象与问题**：把区域、历史变化、文化空间和人地关系转成可讨论、可检验的研究问题。
2. **检索与阅读文献**：从检索式、引用追踪、三遍阅读到比较表和综述。
3. **组织知识库与检索增强**：从材料结构到 chunk、Embedding、BM25、查询改写和 RAG。
4. **准备数据与实验**：先处理单位、标注、切分、基线、指标和可复现记录，再进入模型。
5. **选择文本、视觉和时序方法**：分别完成任务定义、数据准备、工具操作和结果评价。
6. **开展空间与关系分析**：把历史地名、区域尺度、时空关系和社会关系转成可核查的分析对象。
7. **协作与自动化**：组织分工、共享资料、交叉复核及可追踪的批处理，不预设自建系统。
8. **形成论文与研究判断**：让主张、证据、图表和分析过程对应，最后讨论人的判断、责任及 AI 信息回流。

## 第一编 研究对象与问题设计

### 第1章 区域历史学 文化地理学与人工智能研究方法

**原题与补充**：领域通用方法；承接用户明确要求的学科定义、研究范围与简短学术史。六书的范式讨论只提供 AI 科研背景，不代替学科史。

#### 1.1 区域历史学与文化地理学的定义

- **定义与成果**：区分历史过程、区域差异、文化实践与人地关系；产出概念及问题对照表。
- **输入与选择**：既有学术定义与问题，先分清两门学科的研究对象。
- **操作顺序**：梳理定义 → 比较对象和问题 → 标出交叉与不可互代部分。
- **评价与改进**：以概念能否支持实际研究提问检验，修订过宽或循环定义。

#### 1.2 研究对象 区域范围与历史分期

- **定义与成果**：把对象、区域、时间和观察单位写成可讨论的研究范围说明。
- **输入与选择**：材料覆盖、历史地域与当代空间范围；边界可能是设定，也可能是研究结果。
- **操作顺序**：列对象 → 定时间与地域范围 → 选择观察单位 → 写明划分根据。
- **评价与改进**：改变划分条件检查问题是否仍成立；不将今日边界直接套用全部时期。

#### 1.3 简短学术史与问题谱系

- **定义与成果**：说明研究问题从何而来，产出按问题组织的学术史提纲。
- **输入与选择**：有来源可核查的学科研究，不用生成摘要代替文献。
- **操作顺序**：选关键论著 → 整理问题与证据的变化 → 比较争论 → 形成提纲。
- **评价与改进**：检查提纲是否呈现学术问题而非作者名单，回查遗漏与误引。

#### 1.4 AI 统计 GIS 与网络方法的选择

- **定义与成果**：区分 AI 辅助、传统计算与人工解释；产出方法选择图。
- **输入与选择**：研究任务、材料类型、可用资源和成果标准。
- **操作顺序**：列任务 → 配材料 → 对比方法 → 确定人工判断节点与输出。
- **评价与改进**：检查是否确实回答学科问题；不要求每个项目都用全部技术。

### 第2章 问题地图 定义空白 假设生成与可行性评估

**原题与补充**：原题归并 methods.1–4、methods.9。领域补充是历史解释与区域比较的研究条件。

#### 2.1 用 AI 绘制问题地图

- **定义与成果**：将主题展开成研究问题矩阵，而非热点清单。
- **输入与选择**：初步文献、研究兴趣、时空范围；Prompt 给角色、约束和输出格式。
- **操作顺序**：列问题维度 → 生成矩阵 → 逐项补证据需求 → 人工筛选。
- **评价与改进**：按价值、明确性和材料条件比较，纠正只改措辞或追热点的题目。

#### 2.2 定义空白与反向文献检索

- **定义与成果**：从比较中确定已有研究没有回答什么，产出空白说明。
- **输入与选择**：问题矩阵及可核查文献。
- **操作顺序**：反向查相关研究 → 对照对象、尺度、材料、方法与结论 → 写出具体差异。
- **评价与改进**：用原文核查差异，区分未检到与实际未研究。

#### 2.3 假设生成与证伪设计

- **定义与成果**：形成命题、竞争解释与可追踪假设登记表。
- **输入与选择**：适合用证据比较的解释问题；概念辨析不强制改写为预测。
- **操作顺序**：写命题 → 列支持证据 → 列反例和竞争解释 → 让 AI 对抗审查 → 登记优先级。
- **评价与改进**：检查反例是否可能被观察、命题是否仅自我循环，修订过强因果断言。

#### 2.4 可行性评估与最小可行验证

- **定义与成果**：产出资料试查、资源清单和是否推进的决定；计算方法适用时才做 MVE。
- **输入与选择**：材料可得性、整理成本、模型方法和验证能力。
- **操作顺序**：采用72小时冲刺思路 → 试查材料和对读证据 → 若涉及计算则做最小计算对照 → 记录失败原因 → 决定改题或推进。
- **评价与改进**：区分资料不足、方法失效与问题价值不足；计算实验不等于对历史过程做实验。

#### 2.5 AI 辅助选题与最终责任

- **定义与成果**：明确研究者、导师或合作者与 AI 的分工，产出选题决定及理由。
- **输入与选择**：候选题目、可行性结果与真实研究责任。
- **操作顺序**：比较候选 → 讨论取舍 → 记录采用或放弃理由 → 固定研究目标。
- **评价与改进**：由人承担价值和可行性判断，检查是否被模型熟悉题材牵引。

## 第二编 文献阅读与研究知识库

### 第3章 从关键词到语义扩展的三轮文献检索

**原题与补充**：原题归并 methods.5；历史异名、术语演变、多语言和区域检索范围为领域补充。

#### 3.1 关键词 布尔算符与字段限定

- **定义与成果**：建立可复用的检索式与术语表。
- **输入与选择**：研究问题、对象异名、相关概念、语言和数据库字段。
- **操作顺序**：拆分概念 → 列同义异名 → 组合布尔式 → 设字段和范围 → 试检。
- **评价与改进**：用已知重要文献检查漏检，调整过宽和过窄条件。

#### 3.2 第一轮检索 种子论文

- **定义与成果**：获得可追踪的起始文献集。
- **输入与选择**：初步检索结果与纳入标准。
- **操作顺序**：查题录 → 核摘要和全文 → 选种子论文 → 记录纳入理由。
- **评价与改进**：检查种子是否偏在单一时期、语言或学科。

#### 3.3 第二轮检索 前向与后向引用滚雪球

- **定义与成果**：补全研究讨论链和重要早期成果。
- **输入与选择**：种子论文参考文献和被引记录。
- **操作顺序**：向后追源 → 向前追踪 → 筛选新增文献 → 补入研究脉络。
- **评价与改进**：检查转引是否代替原文、引用链是否遗漏不同观点。

#### 3.4 第三轮检索 AI 语义扩展

- **定义与成果**：通过语义邻近发现可核验的新术语和文献线索。
- **输入与选择**：已有问题、术语表、文献集。
- **操作顺序**：生成相关概念 → 转换为实际检索式 → 回到数据库查证 → 筛选新增结果。
- **评价与改进**：比较新增相关性与语义偏移，剔除不存在或无关的文献线索。

#### 3.5 检索日志 去重与覆盖复查

- **定义与成果**：形成可重跑的检索记录、去重文献集与排除表。
- **输入与选择**：三轮结果、检索日期、检索式及筛选理由。
- **操作顺序**：统一题录 → 判重 → 记录排除 → 按时期语言学科检查覆盖 → 定向补检。
- **评价与改进**：区分未收录、未检到和全文不可得；通过复检修正覆盖说明。

### 第4章 三遍阅读 论文拆解与研究综述

**原题与补充**：原题归并 methods.6–7；材料、尺度与历史解释对读为领域补充。

#### 4.1 三遍阅读法的人机分工

- **定义与成果**：形成问题清单、精读记录和论证核查结果。
- **输入与选择**：可定位全文、研究问题和阅读深度。
- **操作顺序**：AI预读提问题 → 对照原文精读论点证据与方法 → 检查论证或计算复现条件。
- **评价与改进**：抽查预读遗漏和幻觉，重要判断均回到原文。

#### 4.2 论文五元组拆解卡

- **定义与成果**：用结构化卡片记录可比较的论文信息。
- **输入与选择**：不同类型论文及共同阅读任务；五元组细目不冒充未见原书正文。
- **操作顺序**：确定适配字段 → 逐项填写并标原文位置 → 对不适用字段作说明 → 形成阅读卡。
- **评价与改进**：检查字段是否服务比较，区分作者判断与阅读者解释。

#### 4.3 AI 聚类与人工仲裁分类

- **定义与成果**：形成经人工确认的文献分类和争议记录。
- **输入与选择**：阅读卡、全文证据与研究问题。
- **操作顺序**：提出分类维度 → AI辅助聚类 → 人工检查类内类间差异 → 调整分类与名称。
- **评价与改进**：用难归类文献检验分类；不能只追求表面整齐。

#### 4.4 文献对照表与论证分歧

- **定义与成果**：比较对象、材料、尺度、方法和结论，产出争论表。
- **输入与选择**：已核阅读卡和分类；先判断不同研究是否可比。
- **操作顺序**：设列维度 → 填证据 → 标一致与冲突 → 回查对象和时期差异。
- **评价与改进**：排除由研究范围不同造成的假冲突，补齐比较中的空白。

#### 4.5 从文献集到综述骨架

- **定义与成果**：形成由研究问题和论证关系组织的综述提纲。
- **输入与选择**：文献对照表、争议与未解决问题。
- **操作顺序**：归并讨论 → 排出论证顺序 → 给判断配来源 → 写出综述骨架。
- **评价与改进**：检查是否比较论证而非罗列文献，修补无依据的综合判断。

### 第5章 按研究问题组织资料与知识库

**原题与补充**：原题归并 methods.8；KB-03–10、KB-17–18、KB-21。材料、整理、生成与解释分层为领域补充。

#### 5.1 知识库目标与研究问题

- **定义与成果**：确定课题库需要完成的查找、比较与写作任务，产出目标表。
- **输入与选择**：研究问题、使用者及预期成果。
- **操作顺序**：列任务 → 定最小内容 → 选条目类型 → 设查找验收问题。
- **评价与改进**：以实际任务成功率验收，不以收藏数量衡量质量。

#### 5.2 本地 云端与混合部署选型

- **定义与成果**：选择满足访问、成本和资料条件的现有路线，产出选型表。
- **输入与选择**：材料使用条件、敏感程度、协作人数和资源。
- **操作顺序**：盘点约束 → 比较三条路线 → 试用必要功能 → 记录取舍。
- **评价与改进**：检查成本、可迁移性和资料边界；不预设自建平台。

#### 5.3 主题 标签与图谱分类

- **定义与成果**：建立问题骨架、横向标签和显式关联。

#### 13.5 M4/M5竞赛遗产与评测口径

#### 13.6 MAE/RMSE/MAPE/sMAPE/MASE指标族
- **定义/成果**：预测误差表及指标选择说明；**输入/选择**：数值预测、对应实际值、尺度与零值条件；**步骤**：选主指标→补充适用指标→统一计算→分时间段比较；**评价/改进**：检查MAPE零值问题、sMAPE局限及MASE基准分母，不能只报有利指标；此处MAE是平均绝对误差。〔TS-11〕

#### 13.7 回测框架实现
- **定义/成果**：逐预测原点的回测记录与汇总；**输入/选择**：锁定窗口策略、模型、预处理与重拟合规则；**步骤**：按原点取历史数据→拟合或更新→预测→保存实际值和误差→汇总；**评价/改进**：每个原点只使用当时可得信息，验证回测用于选择、最终测试回测用于独立报告。〔TS-17.4〕

#### 13.8 概率预测：Quantile Loss CRPS 覆盖率与校准
- **定义/成果**：按需增加的分位数或概率结果及校准表；**输入/选择**：明确不确定性需求、适用模型和足够评价样本；**步骤**：选概率输出→计算适用损失或CRPS→核对覆盖与区间宽度→比较校准；**评价/改进**：不只报覆盖率；Conformal等保证须满足适用条件，不是任意历史序列的无条件保证。〔TS-12；TS-15为选读延伸〕

#### 13.9 公平比较 超参预算与Optuna搜索
- **定义/成果**：公平比较协议、搜索记录和不确定性报告；**输入/选择**：相同切分、预测长度、指标、预算及候选模型；**步骤**：固定预算→选择Grid/Bayesian/ASHA等适用策略→按需用Optuna→仅验证集选型→最终独立测试；**评价/改进**：报告搜索成本，使用适合时间依赖的比较与显著性方法，不把单次领先当稳定增益。〔TS-18–19〕

#### 13.10 消融树 控制变量与消融表
- **定义/成果**：组件对照、消融树和结果表；**输入/选择**：已建立的预测流程、固定数据与评价协议；**步骤**：列预处理/特征/模型组件→规划对照→运行开发集比较→核对交互→形成表格；**评价/改进**：记录失败和资源代价，预测增益不等于历史解释成立；SHAP、Granger或注意力分析只作按需延伸。〔TS-20；TS-16为选读延伸〕

> 深度训练、RLHF/DPO、手写网络或大模型内核、NeRF等仍按全书选读表处理，不因本编展开原子技术节而改为必修。GIS和社会关系分析保留在后续明确标记的领域补充章。

## 第五编 空间分析与社会关系分析

### 第14章 历史地名 地图与时空数据的建立

**依据性质**：历史 GIS 为用户明确补充；地名对照、地图配准、坐标与几何、时间层和位置不确定性的具体流程均为领域通用补充，不冒称六书原图已有完整 GIS 课程。

#### 14.1 历史地名提取 异名同名与地点对照
- **定义与成果**：区分地名、地点及其沿革，形成带来源的地名对照表和地点标识。
- **输入与选择**：地名记载、既有地名资料及时间信息；依据研究范围确定收录对象。
- **操作顺序**：提取地名与时间 → 对照异名及沿革 → 区分同名异地 → 建立地点标识并保留存疑匹配。
- **评价改进**：抽查匹配与来源，随新增材料修订对应关系，避免名称一致即判为同地。

#### 14.2 历史地图选择 控制点与配准
- **定义与成果**：明确地图配准及空间参照，形成可追溯的配准地图与误差记录。
- **输入与选择**：历史地图、可核实参照及控制点；仅对确需转换空间位置的地图配准。
- **操作顺序**：审查地图用途与可辨位置 → 选择控制点 → 执行配准 → 保存参数、来源和误差。
- **评价改进**：检查误差及其空间分布，判断是否满足分析尺度；无需配准的资料沿用已核实参照。

#### 14.3 坐标参考 点线面与几何有效性
- **定义与成果**：区分坐标参考、点线面和区域名称，形成可检查的空间对象与字段说明。
- **输入与选择**：已定位资料与既有空间数据；按对象性质和证据精度选择几何表达。
- **操作顺序**：核实坐标参考 → 建立或转换几何对象 → 连接地点标识 → 记录精度与数据字典。
- **评价改进**：核查坐标一致性和几何有效性，不用单一点位代替仅知所属区域的材料。

#### 14.4 历史边界 时间有效性与分期图层
- **定义与成果**：区分地名变化、地点变化与边界变化，形成按研究分期组织的时空图层。
- **输入与选择**：带时间信息的地点、边界和原始记录；确定资料能够支持的时间分辨率。
- **操作顺序**：记录有效时间 → 对照沿革与边界 → 建立分期图层 → 连接原始记录及版本。
- **评价改进**：检查时间对应与跨期可比性，不用今天的边界替代全部历史时期。

#### 14.5 候选位置 定位精度与不确定性记录
- **定义与成果**：区分精确位置、近似位置、候选位置和仅知区域，形成位置不确定性记录。
- **输入与选择**：定位依据、配准误差、冲突记载及研究尺度；选择与证据相称的表达精度。
- **操作顺序**：汇集定位依据 → 保留候选与分歧 → 标注精度 → 判断是否可纳入拟议分析。
- **评价改进**：抽查不确定位置及其影响；新增证据后修订版本，不以可视化制造虚假精度。

### 第15章 空间分布 区域比较与人地关系分析

**依据性质**：历史 GIS 为用户明确补充；人地关系研究中的空间统计、区域比较、尺度敏感性及解释审查为领域通用补充，不标作原图原题。

#### 15.1 空间对象 观察单位与分布描述
- **定义与成果**：区分地图展示、空间统计描述与解释模型，形成基础分布图和描述指标表。
- **输入与选择**：带时间有效性的空间对象、研究范围与可比属性；确认观察单位、覆盖范围和数量分母。
- **操作顺序**：明确问题 → 固定时间切片与空间单位 → 检查记录机会 → 绘制基础分布并汇总指标。
- **评价改进**：检查缺失、覆盖差异及单位不一致，避免将记录量直接等同于历史现象强度。

#### 15.2 距离 邻近 联系与可达性
- **定义与成果**：区分距离、邻接、空间联系和可达性，形成与研究问题对应的关系结构及指标。
- **输入与选择**：点、面、路径或流动数据；按对象和材料条件选择距离、邻接或联系表达。
- **操作顺序**：界定“接近”或“联系”的含义 → 建立关系结构 → 计算指标 → 记录选择依据。
- **评价改进**：检查空间参照、边界和定位精度的影响，比较不同合理定义下的结果。

#### 15.3 密度 聚集与空间关联
- **定义与成果**：区分密度、聚集与空间相关，形成统计描述、对照条件和结果记录。
- **输入与选择**：空间对象、可比属性及关系结构；确认是否具备适用的零假设或对照条件。
- **操作顺序**：确定指标与对照 → 计算密度或聚集结果 → 比较空间关联 → 保存参数和条件。
- **评价改进**：区分现象聚集与共同来源造成的记录聚集，不由地图颜色直接推出历史机制。

#### 15.4 跨区域 跨时期与人地关系比较
- **定义与成果**：区分区域差异、共变与条件关联，形成比较地图和环境、社会属性对照表。
- **输入与选择**：可比空间单位、时间片、环境或社会属性；确认分母、覆盖与记录机会。
- **操作顺序**：统一比较口径 → 并置区域或时期 → 按研究设计加入属性 → 分开描述差异与拟议机制。
- **评价改进**：核查可比性和材料偏向，以跨时期及跨区域证据检验而非预设解释。

#### 15.5 区域划分 分析尺度与敏感性
- **定义与成果**：说明空间单元、边界、尺度与时间窗口如何影响结果，形成敏感性分析表。
- **输入与选择**：关键空间结果及可替代划分、时间窗口和定位精度；选择有研究意义的变动条件。
- **操作顺序**：列出敏感条件 → 改变区域划分或尺度 → 调整时间窗口与位置精度 → 复算关键结果。
- **评价改进**：报告稳定与不稳定结论，避免仅保留最有利的尺度或边界。

#### 15.6 空间结果 竞争解释与历史过程
- **定义与成果**：区分空间相关、解释假设与历史因果论证，形成结果—材料—机制对应的解释提纲。
- **输入与选择**：空间结果、原文材料、历史过程记录及竞争解释；识别解释所需但尚缺的证据。
- **操作顺序**：回连空间差异与材料 → 并置竞争解释 → 核查历史过程 → 明确支持范围和未决问题。
- **评价改进**：通过原文复核和跨期比较修订解释，不以空间相关单独证明因果。

### 第16章 人物 组织与关系数据的建立

**依据性质**：社会关系网络及族谱来源类别为用户明确补充；实体消歧、关系表结构和来源审查为领域通用补充。族谱仅为来源类别之一，不作为全书统一案例。

#### 16.1 实体 事件 关系类型与纳入规则
- **定义与成果**：区分人物、组织、事件和关系，形成实体与关系类型表、字段及纳入规则。
- **输入与选择**：人物组织记载、名录、往来和事件记录、族谱等；按问题选择亲属、交往、共同活动或组织关联。
- **操作顺序**：明确研究范围 → 定义实体和关系 → 规定时间及字段 → 区分材料陈述、整理确认与分析假设。
- **评价改进**：检查规则是否可执行，不将不同关系无条件混成一条边。

#### 16.2 候选实体抽取 原文位置与证据表
- **定义与成果**：明确候选实体与关系陈述，形成保留原文位置的抽取表和来源证据表。
- **输入与选择**：能支持关系识别的资料；判断方向、强度、时间与缺失范围能否从材料取得。
- **操作顺序**：抽取人物、组织、事件 → 标出候选关系 → 保留原文位置 → 记录来源及证据状态。
- **评价改进**：抽查抽取准确性，单独检查罕见关系及来源记录偏向，保留无法确认项。

#### 16.3 名称 时间 地点与实体消歧
- **定义与成果**：区分确定匹配、存疑匹配和不同实体，形成消歧依据与实体对照表。
- **输入与选择**：名称、时间、地点、关系上下文与来源证据；依据资料完整性选择匹配规则。
- **操作顺序**：汇集候选实体 → 比较多种线索 → 记录合并或区分理由 → 分开确定与存疑匹配。
- **评价改进**：重点抽查易混实体和错误合并，以替代规则重做关键匹配并检验后续影响。

#### 16.4 节点表 关系边表与时间有效性
- **定义与成果**：明确节点、边、方向、权重和有效时间，形成可追溯的节点表与边表。
- **输入与选择**：核查后的实体、关系陈述和证据状态；仅在证据支持时设置方向及强度。
- **操作顺序**：赋予节点标识 → 建立关系边 → 填写方向、时间和来源 → 标注不确定性并连接原文。
- **评价改进**：检查孤立标识、字段一致性和来源可回溯性，不将未知强度写成确定权重。

#### 16.5 重复记录 单层二模分层与数据验收
- **定义与成果**：区分整理重复与真实多重关系，形成单层、二模或分层网络候选数据及验收记录。
- **输入与选择**：节点边表、关系类型与研究问题；依据对象及关系结构选择数据组织方式。
- **操作顺序**：识别整理重复 → 保留真实多重关系 → 生成候选网络数据 → 核查来源和建边规则。
- **评价改进**：改变存疑关系处理与消歧规则重建数据，判断结论是否依赖某一种整理选择。

### 第17章 社会关系网络的描述 比较与解释

**依据性质**：社会关系网络为用户明确补充；建模、网络指标、比较和解释审查为领域通用补充。知识库中的知识图谱不等同于历史社会网络。

#### 17.1 网络边界 关系类型与模型选择
- **定义与成果**：区分记录网络、分析网络与历史社会关系，形成网络定义和建模说明。
- **输入与选择**：已核查节点边、时间和关系定义；选择有向或无向、加权或无权、单模或二模。
- **操作顺序**：固定研究问题 → 确定边界、关系和时间窗口 → 选择网络形式 → 保存建边规则。
- **评价改进**：检查形式是否匹配材料，不把构造出的分析网络当作全部历史关系。

#### 17.2 网络规模 密度与连通结构
- **定义与成果**：明确规模、密度和连通性，形成基本网络描述表及可追溯的网络图。
- **输入与选择**：确定边界的节点边数据；按网络形式选择可比较的描述指标。
- **操作顺序**：输出基本统计 → 检查连通结构 → 绘制辅助图 → 记录数据版本和参数。
- **评价改进**：检查规模及资料覆盖对指标的影响，不把可视化布局本身作为证据。

#### 17.3 中心性 桥接位置与重要节点
- **定义与成果**：区分不同中心性与桥接位置的含义，形成重要节点和关键关系核查表。
- **输入与选择**：建模结果及研究问题；选择能够回答该问题的中心性或桥接指标。
- **操作顺序**：选定指标 → 计算并保存参数 → 回查重要节点和桥接关系 → 解释形成条件。
- **评价改进**：检查高中心性是否来自保存和记录方式，避免直接等同于实际权力或影响力。

#### 17.4 社群识别 边界与划分稳定性
- **定义与成果**：区分算法划分与历史群体解释，形成社群结果、参数和边界核查记录。
- **输入与选择**：网络及关系定义；判断社群问题是否成立并选择相应划分条件。
- **操作顺序**：确定识别目标 → 执行划分 → 回查社群边界与来源 → 比较合理参数下的结果。
- **评价改进**：报告划分稳定性及缺失节点影响，不将一幅社群图直接当作历史群体事实。

#### 17.5 时间 区域 群体比较与缺失敏感性
- **定义与成果**：明确跨期、跨区域和跨群体比较，形成统一口径的结构比较及敏感性记录。
- **输入与选择**：分组网络、覆盖范围、建边规则及存疑关系；先确认规模和资料条件是否可比。
- **操作顺序**：统一指标与规则 → 分期或分组比较 → 改变边界与存疑边处理 → 检验缺失假设。
- **评价改进**：区分结构差异与记录差异，报告对边界、缺失及存疑关系敏感的结论。

#### 17.6 网络结构 来源核验与关系解释
- **定义与成果**：区分结构描述与社会关系解释，形成网络结果、来源和竞争解释并置的论证说明。
- **输入与选择**：关键节点、社群、跨期结果与原文证据；确定哪些解释需要额外材料。
- **操作顺序**：回查关键结构 → 分层核验关系 → 并置竞争解释 → 明确支持范围并修订论证。
- **评价改进**：以来源核验、关系分层与跨期比较改进解释，不从指标排名直接推出历史机制。

## 第六编 集体研究 自动化与论文成果

### 第18章 集体研究的分工 共用资料与交叉核查

**原题归并**：methods.4.4；KB-03。**用户明确补充**：集体研究。完整分工、规范试做、交接与争议处理流程为领域通用补充。

#### 18.1 共同问题 任务拆解与责任分工
- **定义与成果**：集体研究以共享问题、证据标准和责任为基础，形成任务分工表及验收对象。
- **输入与选择**：共同问题、材料范围、成员能力、成果要求和访问边界；不强制采用单一角色结构。
- **操作顺序**：拆解可交付任务 → 确定输入输出 → 按学科判断、整理、执行与复核需求分工 → 指定责任人与复核人。
- **评价改进**：检查任务是否可交接、责任是否清楚，依据执行能力调整任务大小。

#### 18.2 资料标识 数据字典与共同试做
- **定义与成果**：明确共用资料、标注及引用规范，形成数据字典、指南和小样本试做记录。
- **输入与选择**：共享材料、字段和成员理解差异；选择具有代表性及争议的小样本。
- **操作顺序**：统一资料标识 → 制定标注与引用规则 → 共同试做 → 比较分歧并修订指南。
- **评价改进**：检查跨成员数据能否合并，依据试做暴露的问题改进规范，而非直接扩大批量。

#### 18.3 分组执行 版本变更与材料交接
- **定义与成果**：明确交付、版本和未决问题，形成可追溯的交接记录。

- **评价改进**：无法证实即限制解释范围，不以模型置信或反复生成替代证据充分。

#### 23.2 材料 整理 生成 采纳与完整来源链
- **定义与成果**：区分原始材料、整理结果、生成内容与人工采纳，形成可追溯的来源链。
- **输入与选择**：来源、模型输出、人工修改及传播记录；以关键结论为单位组织链条。
- **操作顺序**：列出材料来源 → 标记整理与生成环节 → 记录人工采纳及修改 → 连接最终结论。
- **评价改进**：检查生成内容是否被误当独立来源、来源链是否断裂，补足可核实证据而非重复输出。

#### 23.3 AI 信息回流 循环印证与独立证据
- **定义与成果**：AI 信息回流指生成内容进入知识库、公共传播或后续检索后再次成为依据，形成风险位置与核查记录。
- **输入与选择**：知识库回写、发表传播、相互转引与后续检索记录；区分真正独立证据和同源重复。
- **操作顺序**：追踪生成内容流向 → 找出循环转引 → 回查原始或独立证据 → 对无法证实项停止扩大解释。
- **评价改进**：检验来源链能否打断循环印证，不将多次检索命中或多数输出误作多重印证。

#### 23.4 事实可靠 解释充分与人的价值判断
- **定义与成果**：区分事实是否可靠、解释是否充分、研究是否值得做及应否传播，形成研究立场说明。
- **输入与选择**：证据、模型及研究者选择、对象呈现和群体差异；明确不同判断所需依据。
- **操作顺序**：分开事实与价值问题 → 审查各类选择影响 → 比较解释方向 → 由研究者说明最终判断。
- **评价改进**：区分模型置信、研究者同意和证据充分，不以多数输出外包价值选择。

#### 23.5 最终判断 署名 披露与错误更正
- **定义与成果**：明确不能由 AI 承担的判断与责任，形成判断责任表和成果披露说明。
- **输入与选择**：关键结论、人工采纳、贡献及传播记录；按实际工作和责任确定披露内容。
- **操作顺序**：确定最终判断责任 → 记录署名和贡献 → 说明 AI 参与及限制 → 明确错误更正责任。
- **评价改进**：检查责任是否落实到人、披露是否可核查，确保结论可说明、可争论、可更正。

#### 23.6 生成速度 验证劳动与发表回写原则
- **定义与成果**：区分生成效率、验证成本和学术意义，形成发表及知识库回写原则。
- **输入与选择**：生成数量、核验工作、证据状态和研究价值；不以产出速度决定传播范围。
- **操作顺序**：比较生成与验证负担 → 判断成果意义 → 确定可发表或可回写内容 → 保留来源及生成标识。
- **评价改进**：检查原则是否防止未核验内容扩散，以人的判断、责任与可更正性收束全书。

## 与已弃用三十章方案的五条实质区别

1. **章节由通用研究任务决定，而非由私人项目对象决定。** 不设建筑、老照片、扫描 OCR 或个人工作台的项目章，也不改成泛称后重新插入。视觉方法仍以分类、检测、分割和评价组织。
2. **领域化发生在研究条件中，而非在标题前加地名。** 区域边界、时空尺度、材料形成、语言差异、记录缺失和解释关系实际改变数据准备、切分、方法选择和评价。
3. **原技术标题独立成节，不用四个大筐或“注意事项”替代教程。** chunk、Embedding、BM25、RAG、Prompt、基线、指标、statsmodels 等各有具体技术小节，每节再列输入、操作、成果与评价。
4. **明确新增与来源的边界。** GIS、社会关系网络、集体研究和 AI 信息回流有各自的补充标记；族谱只是一类可用数据，不再锁定全部问题和案例。
5. **不靠技术或章数堆满全书。** 进阶训练、RLHF、手写网络、NeRF 等按需选读；人的价值判断、验证责任和信息回流批评构成结尾的研究论证，而非工程交付后的附带提醒。
