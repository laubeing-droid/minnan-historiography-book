# 第20章：把泉州人口比较做成一项可以复查的小研究

本章回答一个很具体的问题：2010—2020年泉州常住人口增加，为什么它占福建全省人口的份额反而下降？这不是为证明某个预设的地方兴衰故事寻找数字，而是从一句容易误读的话出发，查清材料能够支持什么。

这里使用真实公开公报，不是合成输入。2026年11月12日先核读三份公报，本轮再补核三份，提取四个人口整数，并完成一次有限复算。2010年常住定义已用同次省公报补证，两年11个汇总分区加总通过。它不等于全书独立校对完成，也不等于每一乡镇边界与调查实施误差均已考定。

## 从哪里开始

先读[正文第20章](../../manuscript/正文/ch20.md)，再读[来源与核读说明](SOURCE_REVIEW.md)。[输入表](data/population.csv)只收四个用于计算的整数，[交叉检查表](data/checks.csv)另存公报直接列出的增量和份额；它们不是两批独立调查。完整来源链接、位置和核读日期在[sources.json](data/sources.json)。

有 Python 3 即可运行，不需安装模型或额外依赖。在仓库根目录执行：

```bash
python chapters/ch20/code/reproduce_population.py --out /tmp/minnan-ch20-check
```

命令离线读取仓内表格，不自动联网抓取或修改输入。正常输出为四项公报交叉检查通过，并生成 `calculation.json` 和 `population.svg`。读者可换成自己的输出目录；不要覆盖本次保存的结果后又把它称作原来的运行记录。

本轮实际结果见[计算JSON](results/2026-11-12/calculation.json)、[双面板图](results/2026-11-12/population.svg)与[运行和解释记录](results/2026-11-12/REPORT.md)。图中人数、份额各有自己的单位，两个纵轴都从零开始，只画两次普查时点，不补造中间年份。

## 读结果时要看什么

泉州增加653,755人，增长约8.04%；福建增长约12.59%。分子增长，分母增长更快，份额便从约22.03%降至21.14%。这足以反驳“份额下降就是人数减少”。它不能回答泉州居民是否净迁出，更不能把增长差距直接归因于某项产业或政策。

研究可以在这里完整结束，也可以进一步问人口为什么变化。后一种问题需要出生死亡、迁入迁出、就业与行政统计沿革等新材料，不是把现有四个数字送进更复杂模型就能完成。两个时点也不足以支撑第12—13章的年度预测练习。

第6章的方法可帮助找到和核对公报段落；这里必须回到表头、单位和注释，不能把检索片段当完整材料。第20章则把计算结果变成有限的论证，并明确另一种解释还缺什么证据。这就是本例连接检索、整理、计算和写作的方式。
