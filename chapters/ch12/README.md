## 工作区约定

- `code/` 从附件提升或新写的可运行代码。提升时在文件头加来源注释（原附件路径 + 提升日期）。
- `data/` 本章示例与真实史料数据；真实史料须登记来源与权属，教学虚构数据须标注 `teaching/`。
- `results/` 运行产物；重跑产生覆盖时保留旧版或写明差异，不静默覆盖结论。
- 状态如实：未运行写 **NOT_RUN**；未复核不称完成。协议见[章节工作区总说明](../README.md)。
