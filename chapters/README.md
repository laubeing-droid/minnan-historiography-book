# 章节工作区（活代码层）

本目录是书稿各章**代码推进**的工作区，与写作主线（`manuscript/`）及历史档案（`round1_review/`、`variants/`、`plans/`）分离。正式数据复算与独立校对仍暂停；2026-11-12经用户另行授权完成有限教学代码审计及三份缺陷修补，详见[执行审计](../docs/CODE_EXECUTION_AUDIT.md)。以下协议不代表所有章节代码已提升：

- **历史档案原样保全**：平行校订版、历史版本及复算记录不在此处改写；主线修订须另有作者授权与编写记录；
- **工作区可写**：每章一个目录，把附件中的教材示例或新方法推进为可运行代码。

## 提升协议（教材示例 → 可运行代码）

1. 从 `manuscript/附件/chXX/` 复制代码到 `chapters/chXX/code/`，文件头注明来源路径与提升日期；
2. 登记Python和依赖版本；仅用标准库时写明，不必为了形式新建依赖文件；
3. 教学虚构数据放 `data/teaching/`，真实史料放 `data/` 并登记来源权属——**教材示例与真实历史证据分开**（交接任务书纪律）；
4. 运行产物写 `results/`，与正文数字核对后在章 README 勾选；未运行一律标 **NOT_RUN**；
5. 原附件中的 NOT_RUN / NOT_EXECUTED 历史标记保留；新运行状态另记于执行审计，不回写历史。

当前运行路线见[配套程序怎么跑](../docs/RUNNING_EXAMPLES.md)。下表记录教学检查，不代表正式史料复算或独立校对完成。
