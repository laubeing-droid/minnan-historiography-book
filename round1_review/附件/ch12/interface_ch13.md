# 第12章到第13章输入接口

## 数据与任务

- 数据集：`DEMO_PORT_A`，虚构年度登记件数，`SYNTHETIC_DEMO`。
- 观察范围：1900—1923，公历年度，四位整数年，不是假装发生于元旦的精确时间戳。
- 指标：`registered_items`；单位：`item`；空间口径：`B0`。
- 任务：在各原点可得信息条件下进行数值预测教学；不推断真实历史过程。
- 季节：无依据，不预设固定多年季节周期。第13章独立四期周期例与本例不同。
- 本次代码及所有统计、模型、评价状态：`NOT_RUN`。

## 默认缺失拒收是正确行为

默认`none`不插补，因此`train_input.csv`包含空值。第13章某些教学模型要求完整、规则、可比较的训练前缀，遇到本表应拒绝并说明条件，而不是静默压缩时间轴。适配器只负责字段契约，不负责证明统计模型适用。

若采用`ffill1`，只会增加有限的`input_y`，并不使`y`变完整；来源缺失仍保留。插补值不参与缩放参数拟合，不作为训练标签，也不作为最终评分真值。若下游程序要求“所有位置都是原始观测”，它仍应拒绝插补输入。

## 未来真值的隔离

`evaluation_truth.csv`不能交给模型的`fit`、变换参数拟合、超参搜索或特征选择。只有锁定预测以后，评价器才将相同`series_id + period`的真实目标对齐；仍需核对评价时刻不早于`availability_year`。评价结果不能回流到最终测试方案选择。

同一条1918目标在1918或1919时尚不可得，最早1920才可评价。这不妨碍1917原点对1918发出预测，却妨碍提前用其真值调参或计算当时不存在的成绩。回顾性研究若改用最终修订资料，应另说明采用了不同信息条件。

## 每个回测原点需要重新做的事

1. 固定原点和训练跨度，取得该原点可用的原始资料。
2. 应用同一缺失与缩放规则，拟合只发生在训练范围。
3. 保存该原点参数与掩码，向模型传入明确选择的值列。
4. 锁定预测，最后由评价器读取原始目标并记录其可用时间。
5. 保存失败和拒收原因。没有输出不是零误差，也不能从汇总中悄悄消失。

`window_plan.csv`只是事先写定的窗口例；它没有调用适配器，也没有运行第13章程序。所有文件均应在将来实际执行后才增加具体运行记录。
