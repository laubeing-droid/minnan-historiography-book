## 先看懂五种题设

- 1903年没有原始行。补全年度时间格后，其状态应为`no_record`，不是0。
- 1907年有一行，但题设为字迹不清；1910—1911年为来源缺失。数值保持空白。
- 1914年题设明确为0，状态为`observed_zero`。0是有效值，不应被插补。
- 1918年的题设值直到1920年才可用。在1918或1919原点的训练视图里，该值及原始已观测标记都必须遮蔽。
- 全部原始行的空间口径为B0。脚本不尝试自动处理边界变化，也不按面积重分配数量。

这些是数据设计说明，不是程序已经生成的检查结果。没有刻意设计的季节规律，不允许给年度主例默认设置四期或十二期季节性。

## 运行前需要决定的事

1. 确认现在已进入获准执行与复算的阶段。当前交付不自动开始这一阶段。
2. 使用已有Python 3环境；脚本不需要pandas、statsmodels或任何新安装包。
3. 打开原始CSV和字段字典，确认只处理`DEMO_PORT_A`。事件表与月历表不接受同一处理。
4. 确认信息原点、训练起年、评价末年。默认示例以1915年为原点，训练起年1900，评价至1923。
5. 确认缺失策略。默认`none`；可选`ffill1`只填一个紧邻真实可用值的`no_record`位置，不填来源缺失、字迹不清或尚未可用值。
6. 确认是否需要缩放。默认`none`；`standard`仅用训练内原始且可用观测拟合，补值不参与参数估计。

## 日后获准执行时的命令

在本附件目录内执行下列命令。命令在本次编写中**没有运行**，不能把它当作已验证的终端记录。

```bash
python3 preprocess_annual.py \
  --input data/demo_annual_observations.csv \
  --output demo_origin1915_none \
  --series-id DEMO_PORT_A \
  --origin 1915 \
  --train-start 1900 \
  --evaluation-end 1923 \
  --impute none \
  --scale none
```

程序要求输出目录尚不存在且父目录已存在。不覆盖任何既有文件，不删除失败输出；若已有同名目录，应选择新名称。若将来确有理由比较有限填充与标准化，可另选一个新目录，把参数改为`--impute ffill1 --scale standard`。这一比较需另行执行，不代表当前包已给出效果。

## 执行后应出现的结构

下列是**预期输出合同，不是已经交付的运行文件**：

```text
demo_origin1915_none/
  train_input.csv
  evaluation_truth.csv
  transform_params.json
  run_manifest.json
```

`train_input.csv`只含训练起年到原点的时间位置。`y`是原点已可用的原始值，`input_y`是可选择的算法输入；有补值也不覆盖`y`。`observed_mask`与`available_mask`都按原点遮蔽，原始CSV中后来才知道的有无记录不能作为较早原点特征。`z`仅在选择标准化时填写。`years_since_last_observed`只回看真实且当前可用的观测，不因插补而重置。

`evaluation_truth.csv`专供评价器读取，禁止传给训练、缺失处理和尺度拟合。其`eligible_target=1`仅表示最终原始目标存在，还要等到相应`availability_year`才可评价；这个字段不赋予提前读取标签的权限。某目标为空时，不能以补值评分。

`transform_params.json`记下有效观测数、训练均值、总体标准差、原点及策略。默认不缩放时仍记录这些描述参数，但`z`保持空白；这不是模型拟合。训练方差为0时明示采用尺度1并记录`constant_train=true`。若无任何原始可用观测，则拒绝输出。

`run_manifest.json`仅在未来一次调用写完前述文件后生成，记录该次调用时间、Python版本、输入和程序摘要。它只证明对应调用完成预处理，不证明检验、模型或评价已完成。包内顶层`run_status.json`继续保留原始发布状态，二者不要混用。

## 如何验收一次未来运行

先检查是否有明确错误或部分输出；失败时保留目录以便诊断。核对新输出中的时间顺序、重复键、原点边界、1903空位、1914零值与1918可用性。检查所有数值来源：只有`input_y`允许按明示规则补值，`y`和评价真值不得被填充。再核对缩放参数仅来自训练可用观测，且输出中的模型状态仍是未运行。

本程序只接受等间隔年度非负整数计数，且每条选中序列的指标、单位、空间口径与数据性质必须一致。价格、比例、连续气候变量、月度数据、区间日期、一个年度多个修订值、混合边界或多层地域汇总都不在其当前合同内。遇到这些资料应先修改任务与字段契约，不是绕过检查。

## 与第13章的实际边界

第13章的适配器应读未来生成的`train_input.csv`，不是直接读原始CSV。原始CSV没有掩码，不能假装已经预处理。映射`value=y`、`available_at=availability_year`并保留掩码，不自动改读`input_y`。

本例故意保留缺失，因此可能被第13章要求完整训练前缀的模型演示程序拒绝。这是预计中的合同拒绝，不是适配失败。字段映射成功不意味着材料已满足ARIMA等具体程序要求；若要进行缺失可容纳的模型或另选连续片段，应明确提出新的分析协议。不要偷偷删除缺失年、把它们填成0，或把第13章独立四期教学例的周期搬到本例。
