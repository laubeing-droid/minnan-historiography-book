# 第13章数据字典

## 通用时间与来源

- series_id：同一测量口径的序列编号；各例局部编号不自动跨节连接。
- period：13.2—13.4为1至60抽象等间隔期；13.7/13.10为1至16；13.9为0至15；第12章输入则为公元整数年。不得混用索引。
- available_at：该版本在教学协议中可用于预测的最早期；事件期≤原点并且available_at≤原点才可训练。
- value / y：原始观察；null或CSV空值表示缺失，不等于零。
- source_id / id：本包fiction教学行定位，非史料档案号。
- unit：数值单位；teaching_unit不具真实历史计量意义。
- origin / horizon / target：作预测的期、第几步、目标期；target=origin+horizon。
- fit_id：将预测连接到当次输入与拟合记录的标识。

## 输入表

13.1 forecast包含训练、答案和周期；classification每个实体有长度三的values与0/1标签，训练/测试实体隔离；anomaly标签1为研究定义的异常，不由阈值生成；generation参照不参与训练参数。

13.5 train、actual和forecasts各自分离，底层A/B可加；prices与weight_window只用于训练金额权重。TOTAL由底层相加派生，不是第三份独立观测。

13.6 m为MASE训练周期；available_at仅约束评分参照。P/Q是人工预测，不是模型名。aggregation.ids与weights为事前声明的跨序列汇总，不根据结果剔除C/D。

13.7/13.10 history和truth分离。候选method为mean或last；window为日历长度，null为扩展；fill为drop或ffill。ffill仅向当前窗口内部的过去查找，且不填尚未公布项。validation_cutoff为选择时评分截止，test_cutoff为最终报告截止。

13.8 levels为严格在0与1之间的分位数水平，predictions不得交叉；members是等权经验分布成员，重复成员不能去重；nominal为区间名义覆盖率。

13.9 candidates中id是并列裁定键；transform只允许identity/log1p；budget把完成、失败和重复均算入。seeds仅控制抽样，不是独立历史样本。

## 结果状态

success/failed描述预测是否产生；scored/missing_or_late_truth/prediction_failed描述评分条件。planned、predicted、scored是不同分母。预测生成覆盖率不等于概率区间命中率。MAE/RMSE保留单位；MAPE/sMAPE按百分数；sMAPE双零未定义；MASE训练尺度零时未定义。null不替代为零。NOT_RUN是交付状态，只有读者真实执行后生成的日志才可标EXECUTED_BY_READER。

## 完整化的新设定

60期CSV是重新编制，不是旧输入恢复。13.1的完整生成训练/参照、13.6的C训练值及Q在C/D的补充预测、13.9最早八期补全均以教学完整性为目的；原文未明列的旧数值不作相同承诺。
