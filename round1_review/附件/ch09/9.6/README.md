# 9.6 人工标注质量管控：指南 一致性与歧义样本 附件

本目录是2026年10月30日为新结构重编的自包含教学练习，不是遗失旧读者包的原字节恢复。输入是编者构造或预置判断，非史实、非模型输出。正文旧例保留用于阅读方法，不能拿它的数值充作本输入的输出。

## 先做什么

沿用7.4的一致性办法，但把指南具体化为文本证据：标签之外再交最小支持片段和字符位置。重新试标时先遮住教学答案；对“中断”是否等于停讲写清任务口径。若标注者标签相同但引了不同动作，也要纳入讨论。把仲裁理由放进歧义表，以便以后增加跨语言材料时知道要保持哪一条语义边界。

## 文件与使用

- input.json：脚本实际读取的输入和配置，UTF-8。
- input.csv：同一教学样本的表格阅读副本；列表或对象使用JSON字符串。编辑后须同步JSON，程序不会自动合并两份。
- field_dictionary.json：字段填写依据和待补定义。
- worksheet.md：本节具体操作记录。
- result_template.csv：待填结果，当前NOT_RUN，不是已完成输出。
- ../workbook.py：本章标准库教学脚本，依据mode选择本节操作。

## 读者需要运行时

进入本目录，使用已有Python 3执行：

```text
python -B ../workbook.py --input input.json
```

脚本只读本地输入并在终端打印JSON，不联网、不安装、不调用模型、不修改输入、不自动保存结果。需要留存时，先确认新文件名，再自行保存终端输出。2026-10-30已在本次复核环境实际执行本节所列标准库命令，并对关键输出独立计数或计算；详细状态见[本章运行记录](../EXECUTION_STATUS.json)。这不等于已在所有读者环境验证，也不表示运行过模型或获得历史研究结论。result_template.csv及未填worksheet仍是空白模板，不充作运行结果。

## 看什么结果

成果应为：带证据位置的标注模板与歧义案例表。先从一条编号回到原句或像素，再解释汇总的分母。分母为零时脚本输出null而不是伪造零分。

判断题：标签一致而依据不同，是否足以成为稳定的评价参考？
