## 数据字典

| 字段 | 应填内容 | 易错处 |
|---|---|---|
| 资料号与位置 | 对应一件材料及具体条目 | 重排后改变编号所指 |
| 形成时间 | 文本编写或署年 | 当作所述事件时间 |
| 事件时间 | 原文明确的行动时间或区间 | 把筹议、开工、完工合成一个年 |
| 原文转录 | 材料字词，补字与疑字另示 | 为通顺改成研究结论 |
| 主体 | 原文出现的名称 | 同名就合并 |
| 行为原词 | 垫银、倡助、桥成等 | 统一改成“捐款” |
| 金额及单位 | 原数原单位 | 未记金额填零；擅换现代币值 |
| 当前解释 | 有根据的材料判断 | 与原文混在一栏 |
| 待核问题 | 哪个关系尚未确认 | 笼统写“待深化” |

缺失值采用中文说明：原文未记／字迹难辨／不适用／尚未查完。它们均不自动等于零。
