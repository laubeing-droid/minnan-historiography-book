本版新制教材配套。真实来源的整理值、教学设例、空白模板分开标记。本轮分项运行与核对结果见 execution_receipt_20261030.json；其中模型调用与实际计算分别记录，不以文件结构检查替代内容判断。

本章不是算法竞赛，不把科研品味或价值判断化成统一分数。

先读[三个选题卡](question_cards.json)，按[比较工作表](comparison_worksheet.md)写出取舍；再使用[空白问题卡](question_card_template.md)。[学习记录](learning_log_template.csv)与[一次复盘](reflection_example.md)说明如何把“改对一句话”转成可迁移的能力。

附件不含私人聊天或田野经验。例子均来自本书公开案例和明确设定的练习；作者的历史哲学立场在正文展开，不靠教学分数证明。
