# 8.8 独立测试与方法复现 附件

本目录是2026年10月30日为新结构重编的自包含教学练习，不是遗失旧读者包的原字节恢复。输入是编者构造或预置判断，非史实、非模型输出。正文旧例保留用于阅读方法，不能拿它的数值充作本输入的输出。

## 先做什么

先把固定方案里的词表与否定条件写好，把不含参考列的 input.json、input_blind.csv、固定方案 locked_plan.json 与 workbook.py 交给执行者；reference.csv 及评分脚本由评分者保管。两份文件按 id 相连，不以行序猜对应关系。示范句已经出现在前面，因而本包只能演示交接程序，不能称为独立历史测试。真实项目须另取未参与规则选择且按原件分组的材料。

## 文件与使用

- input.json：脚本实际读取的输入和配置，UTF-8。
- input.csv：同一教学样本的表格阅读副本；列表或对象使用JSON字符串。编辑后须同步JSON，程序不会自动合并两份。
- field_dictionary.json：字段填写依据和待补定义。
- worksheet.md：本节具体操作记录。
- result_template.csv：待填结果，当前NOT_RUN，不是已完成输出。
- ../workbook.py：本章标准库教学脚本，依据mode选择本节操作。
- input_blind.csv：预测者输入，不含参考列。
- reference.csv：评分者持有的预置参考。
- locked_plan.json：交接用固定方案。

## 读者需要运行时

进入本目录，使用已有Python 3执行：

```text
python -B ../workbook.py --input input.json
```

脚本只读本地输入并在终端打印JSON，不联网、不安装、不调用模型、不修改输入、不自动保存结果。需要留存时，先确认新文件名，再自行保存终端输出。2026-10-30已在本次复核环境实际执行本节所列标准库命令，并对关键输出独立计数或计算；详细状态见[本章运行记录](../EXECUTION_STATUS.json)。这不等于已在所有读者环境验证，也不表示运行过模型或获得历史研究结论。result_template.csv及未填worksheet仍是空白模板，不充作运行结果。

## 看什么结果

成果应为：方案快照、盲输入、参考表与交接记录。先从一条编号回到原句或像素，再解释汇总的分母。分母为零时脚本输出null而不是伪造零分。

判断题：独立性来自未参与选择的材料，还是来自给文件换一个test名称？

## 迁移真实课题

另建课题输入版本，替换教学来源与编号，保留原文或图像位置；不要把其他节的独立例子合并成更大样本。模型调用、下载数据和训练不由本脚本执行，若采用需另记录模型和数据版本、来源切分、成本和实际状态。

实现依据：Python官方[csv](https://docs.python.org/3/library/csv.html)与[json](https://docs.python.org/3/library/json.html)文档。接口出处与本次执行检查分开记录；通过教学输入及边界检查，不等于证实真实研究的历史结论。

预测者把实际终端输出另存为一个新JSON后，评分者可执行 `python -B score_predictions.py --predictions 读者新保存的预测.json --reference reference.csv`。这里的预测文件应由读者真实运行产生，本包不伪造该文件。score_predictions.py亦已用实际生成的预测执行，并检查重复、缺号及非法二值输入。

固定方案locked_plan.json是人工可读快照；此教学脚本使用workbook.py中的固定rule实现，并不从该快照动态加载词表。更改方案时须同步核对实现并在新的开发材料上重新检查，不把改过的方案当作原锁定方案。复核已在不含reference.csv的单独交接目录实际执行预测，并确认逐条输出相同。
