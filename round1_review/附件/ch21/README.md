# 投稿与回应教学包

本版新制教材配套。真实来源的整理值、教学设例、空白模板分开标记。本轮分项运行与核对结果见 execution_receipt_20261030.json；其中模型调用与实际计算分别记录，不以文件结构检查替代内容判断。

所有稿名、投稿信、审稿意见、回应及修改段均为教学虚构，没有真实投稿、审稿或录用。

1. 读[来源身份表](sources.csv)与[未决问题](unresolved_materials.md)。
2. 看[教学信](cover_letter_teaching.md)，确认贡献只到来源辨析。
3. 对照[虚构意见](reviewer_comments_teaching.md)、[回应](response_teaching.md)、[修改段](revised_passages_teaching.md)及[对应表](response_matrix.csv)。
4. 用[提交前清单](submission_checklist.md)补齐自己实际确认的事项；本包不代为确认原创、在投或共同作者同意。
5. 可执行 `python -B check_response_NOT_RUN.py` 检查M1—M3能否对应。脚本不投稿，不检查政策现行性，也不评价史实。

第5章的桥梁笔记是共同案例入口，见[第5章附件](../ch05/README.md)。本包只重复投稿所需的来源身份字段，不把多份表当成独立证据。
