# 研究范围与对象表

对应正文1.1。先用一段话说明要解释什么，再填表。只填写与问题有关的类别，不为凑齐类别强行扩题。下列示例是拟议题目，不报告历史调查结果。

## 空白模板

研究问题：

| 对象或活动 | 主要观察人群 | 时期与地域依据 | 已有材料或材料入口 | 纳入理由 | 暂不承担的判断 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

范围说明：本文考察____在____时期、____地方的____变化。主要材料是____。纳入____是因为它参与____；暂不讨论____，原因是____。

## 教学填写示例

| 对象或活动 | 主要观察人群 | 时期与地域依据 | 拟寻找材料 | 纳入理由 | 暂不承担的判断 |
|---|---|---|---|---|---|
| 女童就学 | 学生、家长、教师 | 教学设定1920—1940年若干村落 | 名册、校规、家庭书信 | 解释已有入学经历与家庭安排 | 全县女童入学率 |
| 日常劳动 | 同一批学生家庭 | 仅追与就学有关的家庭 | 劳作记述、费用记录 | 检查上学与家务、生产安排的关系 | 全地区劳动结构 |
| 跨县就学 | 在名册出现的外县学生 | 依实际就读联系纳入 | 居住信息、路线与招生规定 | 说明县界不能完全代表就学范围 | 外县全部教育状况 |
| 海外捐款 | 暂未纳入 | 尚无对应材料 | 待有线索再查 | 不能只因题目属于闽南便预设 | 侨资推动教育的总体解释 |

## 使用说明

1. 把“准备寻找”与“已经取得”分开。材料入口不是现成证据。
2. 范围改变时只补一句理由，例如发现有跨县就学，增加其居住地，不顺势把全县纳入。
3. 完成后用一句话检查：去掉地方文化标签，是否仍能说清具体人群做了什么？不能说清就继续缩小。
